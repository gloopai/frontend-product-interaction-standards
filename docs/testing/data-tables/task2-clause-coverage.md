# 数据表格规范分句覆盖清单

本文件只提供测试映射：每行把 `references/data-tables.md` 中一个规范分句绑定到一个具体验收 ID 和一个可观察断言。规范内容及其唯一 owner 始终是 `references/data-tables.md`；本清单不得新增、替代或弱化规则。

结构审计必须确认：clause ID 全局唯一；每条规则从 `.a` 开始连续且完整；每个表格数据行恰有一个 clause ID 和一个验收 ID；所有规则与验收引用均存在。
