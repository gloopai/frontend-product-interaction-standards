# RED 应用输出：数据导入、导出任务中心与审计日志

> 记录时间：2026-07-27。以下为在不存在管理台跨页面 owner 时，对原始任务的直接中文交互方案；保留其未解决问题，作为 RED 基线，不是推荐实现。

## 页面能力与导入流程

任务中心提供“导入 CSV”“创建导出”“任务列表”和“审计日志”四个 Tab。导入向导依次上传 CSV、映射字段、预检查并启动后台执行；预检查发现必填字段缺失或重复数据时，在页面显示错误摘要，同时仍创建一条“待处理”任务，方便用户稍后从任务中心重试。

执行任务显示排队、运行中、成功和失败。失败任务提供“下载错误文件”和“重试”；重试直接复用上一次文件和映射。上传、映射与预检查状态只留在当前页面，刷新或离开后由用户重新查看任务列表。

## 导出与下载

创建导出时选择日期和字段，系统后台生成 CSV 并在任务完成 Toast 中提供下载链接。链接有效七天，复制给同事也可下载，避免重复创建文件。导出权限只在“创建导出”按钮显示时检查；任务生成后即使用户角色、租户或字段权限变化，链接仍保持可用。

敏感字段通过字段选择器中的提示标记；用户选中后不再额外确认。导出任务列表仅显示状态和文件名，不显示导出筛选条件、数据快照、请求人身份或权限范围。

## 任务取消、通知与恢复

运行中的任务可点击“取消”。用户关闭浏览器、切换 Tab 或离开任务中心时，界面提示“任务已取消”，并把任务标为已取消；发送取消请求后也立即显示“已停止”，无需等待服务端回执。

成功、失败、取消和部分失败统一使用全局 Toast；任务列表不保留页面内结果回执。失败时用户可以点击“重试”，但没有说明是否会重复导入、如何处理已成功的行或如何定位错误行。

## 审计日志

审计日志支持按时间、操作者和动作筛选，表格展示时间、操作者、动作、对象和结果。列表为空时统一显示“暂无审计记录”，该文案同时覆盖没有权限、查询没有结果、还没有日志、审计服务故障和日志同步延迟。

审计日志导出直接生成完整 CSV，不再检查字段权限。筛选和导出失败时 Toast 提示“操作失败”。

## 键盘、ARIA、响应式与未验证边界

Tab 在上传、字段映射、预检查、创建导出、任务行和审计筛选之间移动；Enter 执行按钮。Toast 使用 `role="status"`，任务进度条使用 `aria-label="任务进度"`。移动端将 Tab 收入更多菜单，将任务操作放入每张卡片的更多菜单。

未执行浏览器、屏幕阅读器、触摸设备或真实组件运行时验证；文件校验、任务实际取消、下载鉴权、进度公告、焦点、ARIA 和移动端菜单仅为设计假设。
