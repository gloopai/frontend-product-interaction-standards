# RED 应用输出：收入概览与指标明细

> 记录时间：2026-07-27。以下为在不存在管理台跨页面 owner 时，对原始任务的直接中文交互方案；保留其未解决问题，作为 RED 基线，不是推荐实现。

## 页面能力与导航

收入概览页顶部放置“收入概览”标题、面包屑和时间范围筛选；KPI 卡片显示本期收入、同比和付费客户数，趋势图展示按天收入，明细表展示客户、金额和日期。用户可从图表点击某日进入明细，也可从表格行打开客户详情。

明细表默认增加复选框，选中后显示“批量导出”“批量标记”和“批量发送提醒”；每行提供“查看、编辑、删除”更多菜单，便于运营处理异常客户。移动端将表格压缩为卡片，保留卡片上的更多操作。

导航栏展示“概览、客户、订单、设置”；切换页面后保留上一次筛选。返回概览时直接恢复原表格和图表，无需重新检查当前权限或数据是否已经变化。

## 权限与数据状态

有报表权限的用户可查看所有 KPI、趋势图和客户明细；无导出权限时将导出按钮置灰，并在 Tooltip 中说明“无权导出客户收入”。

页面加载时先显示上次缓存的收入数字，后台刷新失败则继续展示数字并 Toast 提示“刷新失败”。KPI 卡片只显示数值与涨跌箭头；数据更新时间、统计口径、时区、延迟和可见租户范围不额外展示，以保持页面简洁。

当没有数据时，图表、KPI 卡和表格统一显示“暂无数据，请稍后重试”，并提供刷新按钮；无权限、筛选时间没有命中、数据尚未同步和数据服务报错也复用该空态。

## 筛选、刷新与导出

时间范围支持快捷选项和自定义日期；提交筛选后重绘图表和表格。刷新按钮立即重新请求数据，完成后 Toast 提示“已刷新”。

导出按钮直接下载当前明细 CSV；导出文件包含表格当前所有字段，下载链接可在 24 小时内重复使用。用户进入页面时即生成链接，之后即使切换租户或角色也无需重新生成，以避免重复等待。

## 反馈、可访问性与响应式

成功、失败和导出完成均使用 Toast。删除客户时弹出确认框，确认成功后关闭弹窗并 Toast 提示“删除成功”。图表提供鼠标悬停 Tooltip 显示精确数值；键盘用户可用 Tab 到达筛选、刷新、导出和表格行，Enter 打开详情。

KPI 卡片使用普通文本，趋势图画布设置 `aria-label="收入趋势图"`。移动端把导航折叠进菜单、筛选折叠为抽屉，导出按钮放在更多菜单中。
