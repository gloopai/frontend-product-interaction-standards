# 穿梭框、分配列表与授权资源选择 RED 摘要

本 RED 摘要记录本轮新增审计覆盖的失败类型：

- 两个普通 Select、两个普通表格或组件库 Transfer 默认状态伪装成完整分配 owner。
- 只用 `selectedKeys`、`targetKeys`、`checkedKeys` 或两个数组表达授权会话。
- 移动即保存，勾选即移动，搜索命中即已分配。
- 当前页全选、全部筛选结果、全部候选、跨页选择和排除项混用。
- 从当前 DOM、当前可见行、旧 checked keys、旧候选或旧已分配摘要推导提交范围。
- 无权限状态泄露资源名称、路径、父级、子级数量、成员数量、授权关系、内部 ID、旧 tooltip 或旧 aria-label。
- 无权限、只读、锁定、继承、已删除、失效、重复和未知状态被合并。
- 树形半选、懒加载未完成或过滤后部分节点被当成可提交全量授权。
- Toast 作为唯一保存失败、部分成功、未知结果、权限拒绝或版本冲突回执。
- 移动端删除候选搜索、已分配摘要、待保存差异、移动/移除、应用/取消、权限原因或错误恢复。
