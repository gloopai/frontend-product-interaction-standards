# 反馈状态规范 RED 基线总结

没有 Feedback States owner 时，常见失败包括：

- `feedbackState` 被降级为 `loading`、`error`、`empty` 三个布尔值，无法表达 stale、partial、unknown、permission 和 recovery。
- 首次加载和刷新失败不区分；刷新失败时保留旧内容，不能直接清空旧内容。
- Skeleton 包含可操作假数据、假按钮、假复选框或假链接。
- 数据源为空、筛选无结果、未配置和无权限都共用“暂无数据”。
- 空态给无权限用户展示不可执行 CTA。
- Toast 成为唯一错误或结果回执。
- 部分结果和未知结果被伪装成成功或失败。
- 无权状态不得泄露对象名称、数量、字段、文件名、筛选值或错误明细。
- 移动端不得删除主要恢复入口；常见坏例是删除重试、清空筛选、申请权限、返回、任务中心或查看错误。

浏览器、屏幕阅读器、触摸设备和真实组件运行时未执行，保持未验证。
