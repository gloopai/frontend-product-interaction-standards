# 项目接入门禁 GREEN 摘要

## 目的

记录通用接入包在当前仓库内满足强制加载、冲突裁决和项目隔离要求。

## 当前通过条件

- 接入片段要求前端交互任务开始前读取本地 Skill。
- 接入片段要求按 Skill 路由读取适用 `references/*.md`。
- Skill 或必需参考文件不可读时，接入片段要求停止受影响工作。
- 接入片段禁止凭记忆、旧复制规则或组件库默认行为继续。
- 接入片段声明项目本地规则与 Skill 同时适用，并在冲突时停止请用户裁决。
- 接入片段要求最终回复披露已读取规范、已运行检查和未验证运行时检查。
- 接入文档保持项目无关，不包含业务项目专属名称、页面或模块。

## 边界

当前验证只覆盖通用 Skill 仓库文档。任何具体业务项目接入仍需单独检查该项目的 `AGENTS.md` 和实际任务执行记录。
