# 项目接入门禁 RED 摘要

## 目的

验证接入文档审计能捕获会导致业务项目绕过共享 Skill 的关键缺口。

## 已覆盖负向变异

- 移除 `~/.codex/skills/frontend-product-interaction-standards/SKILL.md` 后，审计必须失败。
- 移除 `references/*.md` 路由读取要求后，审计必须失败。
- 移除 Skill 不可用时停止受影响工作的规则后，审计必须失败。
- 在通用接入片段中泄露业务项目专属名称后，审计必须失败。

## 边界

该 RED 只验证接入文档的结构化门禁，不替代具体业务项目的真实 `AGENTS.md` 复核，也不验证浏览器、键盘、屏幕阅读器或触控设备行为。
