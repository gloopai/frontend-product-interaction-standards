# 页面操作栏与列表工具栏 GREEN 证据摘要

合格规范必须证明：

- `toolbarState` 明确声明工具栏 owner、结果绑定、选择绑定、视图工具、权限和响应式策略。
- 页面主操作只有一个 `primary owner`，并在稳定标题区或主操作区可发现；不能被埋进无标签更多菜单作为唯一入口。
- 结果工具栏读取已应用筛选和当前结果 owner，不读取筛选草稿、Select query、旧结果或旧权限。
- 批量操作栏只在 Data Table `resolvedTier=bulk-action` 且存在有效选择时出现；只读报表、row-action 列表、无选择或失效选择不会出现空批量条。
- 更多菜单只收纳低频或空间不足的次要能力；错误恢复、权限原因、主操作入口和导出回执不能只放在更多菜单、Tooltip、Toast 或浏览器提示里。
- 权限、租户/工作区、能力开关或结果 owner 变化后，工具栏原子重算可见操作、禁用原因、批量条、导出入口和视图工具。
- 移动端可以收纳低频工具，但不得删除新增、刷新、错误恢复、已选摘要、批量入口、导出恢复或主要视图工具。
- 浏览器、触摸设备、屏幕阅读器、真实组件和真实移动端视口检查仍是未验证，具体页面接入时必须补充。
