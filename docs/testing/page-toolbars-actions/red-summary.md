# 页面操作栏与列表工具栏 RED 证据摘要

以下场景必须判失败：

- 没有 `toolbarState`，或页面操作栏、结果工具栏、批量条、视图工具由多个 owner 随意写入。
- 页面主操作没有 `primary owner`，新增或创建入口被埋进无标签更多菜单作为唯一入口。
- 结果工具栏读取筛选草稿、Select query、旧结果或旧权限，导致刷新、导出、列设置或视图切换作用在错误范围。
- 只读报表、row-action 列表、无选择状态或选择失效后仍显示空批量条。
- 更多菜单、Tooltip、Toast 或浏览器提示成为唯一错误恢复、权限原因、主操作入口或导出回执。
- 权限、租户/工作区、能力开关或结果 owner 变化后，旧操作、旧批量条、旧导出入口或旧视图工具没有原子收敛。
- 移动端删除新增、刷新、错误恢复、已选摘要、批量入口、导出恢复或主要视图工具，而不是放入可访问的收纳入口。
- 没有执行浏览器、触摸设备、屏幕阅读器、真实组件和真实移动端视口检查时，不能写成已验证，必须标为未验证。
