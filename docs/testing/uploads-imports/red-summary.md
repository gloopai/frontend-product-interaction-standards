# 上传与导入规范 RED 基线总结

没有 Upload / Import owner 时，常见失败包括：

- 把浏览器 `accept` 当成唯一文件校验，缺少类型、大小、数量和业务可解析性校验。
- 类型不符、大小超限、空文件或重复文件仍进入待上传请求队列。
- 没有稳定 `sessionId`、文件项身份和上传会话，迟到结果会写回新文件。
- 重复点击、Enter、Space、触摸或事件重放造成重复上传或重复导入任务。
- 关闭 Dialog、路由离开或点击取消后，直接把已发送服务端任务写成服务端已取消。
- 跳过导入预检，或预检没有区分格式错误、字段缺失、字段映射、重复数据、权限不可执行、警告和可继续风险。
- 部分成功只用 Toast 表示，没有成功数、失败数、跳过数、影响范围、下一步和错误明细入口。
- 错误明细下载不复核权限、租户/工作区、任务身份和文件有效期。
- 表单 reset 或 route/unmount 误释放其他上传会话或已提交任务。
- 拖拽上传不能是唯一入口；移动端只保留拖拽上传，或者窄屏删除查看错误、重试、确认导入和错误明细下载路径。

浏览器、屏幕阅读器、触摸设备和真实组件运行时未执行，保持未验证。
