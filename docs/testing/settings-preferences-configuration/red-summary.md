# 设置、偏好与配置页 RED 证据摘要

以下场景必须判失败：

- 没有 `settingsState`，或缺少 `settingsScope`、`draftSettings`、`effectiveSettings`、`defaultSettings`、`applyMode`。
- 设置项没有作用域，用户偏好、租户配置、项目配置和集成配置混用同一状态。
- `draftSettings` 被当作 `effectiveSettings` 展示，用户切换控件后界面声称配置已经生效。
- `applyMode` 不清楚，即时生效和显式保存混在同一页却没有说明。
- 保存、取消、恢复保存值、重置默认、继承默认和清空自定义都写成一个“重置默认”入口。
- 高风险设置绕过风险 owner；权限降级后旧草稿、旧默认值、旧保存按钮或旧集成状态仍可见。
- 部分成功、失败、冲突或未知结果被 Toast 写成保存成功。
- 移动端删除保存/取消、脏状态、作用域说明、默认值说明、危险确认、错误摘要、审计回执或恢复路径。
- 未执行真实浏览器、触摸设备、屏幕阅读器、权限切换和移动端视口检查时，不能写成已验证，必须标为未验证。
