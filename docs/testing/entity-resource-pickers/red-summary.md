# 对象、资源与成员选择器 RED 摘要

本 RED 摘要记录本轮新增审计覆盖的失败类型：

- 普通 Select 伪装对象选择器。
- display label、头像、邮箱、路径、tooltip 或 aria-label 被当作对象身份。
- 搜索结果、最近项、收藏、推荐和已选实体未分层。
- 旧搜索结果、旧最近项、旧推荐项或旧缓存继续提交。
- 跨租户、跨工作区、跨账号、跨项目或跨权限边界缺少可见且可绑定证明。
- 无权限状态泄露对象名称、头像、邮箱、路径、父级、数量、成员关系、内部 ID 或旧缓存。
- 已失效、已删除、无权限、不可绑定、重复、只读和未知对象被合并。
- Toast 作为唯一选择失败、权限拒绝、对象失效或绑定结果回执。
- 移动端删除搜索、已选摘要、删除、清空、应用、取消、错误说明或权限原因。
- 未真实验证却声称浏览器、键盘、读屏、触摸、权限切换或移动端视口已验证。
