# 项目接入检查清单

这份清单用于检查业务项目是否已经强制接入 `frontend-product-interaction-standards` Skill。它只评估接入门禁，不评估具体页面是否符合所有交互规范。

## 必过项

项目满足以下全部条件，才算完成接入：

1. 项目根目录或对应前端子目录存在 `AGENTS.md`。
2. `AGENTS.md` 覆盖所有前端页面、组件、表单、列表、表格、Dialog、Drawer、按钮、管理台、响应式和交互行为。
3. `AGENTS.md` 明确要求实现或评审前读取 `~/.codex/skills/frontend-product-interaction-standards/SKILL.md`。
4. `AGENTS.md` 明确要求按 Skill 路由读取所有适用的 `references/*.md`。
5. `AGENTS.md` 明确声明 Skill 或必需参考文件不可读时，停止受影响工作并报告阻塞。
6. `AGENTS.md` 明确禁止凭记忆、旧复制规则或组件库默认行为绕过 Skill。
7. `AGENTS.md` 明确项目本地规则与 Skill 同时适用，更严格且兼容者优先；冲突时停止并请用户裁决。
8. `AGENTS.md` 要求最终回复列出已读取规范、实际运行检查和未验证运行时检查。
9. `AGENTS.md` 明确项目专属例外只留在业务项目，不得复制回共享 Skill。
10. 项目没有把完整通用规范复制为新的长期事实来源。

## 通过判定

满足全部必过项，并且项目本地规则只补充技术栈、命令、模块、业务例外或安全边界，不削弱 Skill 中的通用交互 owner。

## 失败判定

出现以下任一情况，应视为未完成接入：

- 没有 `AGENTS.md`，或 `AGENTS.md` 未覆盖前端交互任务。
- 只依赖 Skill 的隐式触发，没有项目级强制读取要求。
- 只复制了某几条旧规则，没有读取 `SKILL.md` 和适用 `references/*.md` 的要求。
- Skill 不可读时仍允许继续实现。
- 允许组件库默认行为覆盖已加载规范。
- 项目本地例外没有范围，或试图把业务项目偏好写回通用 Skill。
- 最终回复不要求披露已加载规范、已运行检查和未验证项。

## 建议复核方式

1. 阅读项目 `AGENTS.md`，用“必过项”逐条标记通过或失败。
2. 如果项目存在旧复制规则，确认它们没有替代共享 Skill，也没有与共享 Skill 冲突。
3. 抽取一个前端交互任务，确认 Agent 会先读取 Skill，再读取适用 `references/*.md`。
4. 若发现冲突，先修项目接入门禁；不要改写共享 Skill 来适配单个业务项目。
