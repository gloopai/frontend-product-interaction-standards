# HANDOFF 交接状态刷新设计

## 目标

让 `HANDOFF.md` 准确反映已推送到 `origin/main` 的规范加固结果，为下一阶段“表单字段、校验、提交与错误恢复”提供可信起点。

## 修改范围

- 将“当前交接版本”更新为实施时的 `origin/main` 提交。
- 在现有四类规范摘要中补充本轮新增保证：跨形态关闭生命周期、路由或卸载处置、Select placement 转换焦点与 ARIA、方向相关模态基础设施切换。
- 在当前结构中补充已纳入仓库的设计、实施计划和审计文档目录。
- 在验证状态中记录官方 Skill 校验、相对链接、占位符、完整差异检查、独立 RED/GREEN 与评审结果。
- 明确浏览器、屏幕阅读器、触控设备和真实业务组件测试仍未执行。
- 保持表单规范为下一优先级，不在本次加入表单规则或修改规范正文。

## 文件职责

- 仅修改 `HANDOFF.md`。
- 不修改 `SKILL.md`、`README.md`、`agents/openai.yaml` 或 `references/*.md`。
- 不复制审计报告的完整矩阵，只链接并摘要其结论。

## 验证

- 核对交接版本与 `origin/main` 一致。
- 检查 `HANDOFF.md` 中的相对链接均存在。
- 扫描未完成占位标记。
- 运行官方 Skill 校验和 `git diff --check`。
- 审查最终差异，确认只有 `HANDOFF.md` 发生内容修改，设计文档作为本次流程记录单独提交。
