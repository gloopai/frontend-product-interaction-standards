# 批量操作与批处理动作交互规范设计

## 背景

管理台高频列表常把“批量操作”混在表格、按钮或审批里处理，导致范围不清、跨页选择误判、权限变化后旧选择可提交、部分成功只用 Toast 提示、错误明细不可恢复等问题。本设计新增独立 owner，让批量操作成为可审计的意图、请求和结果链路。

## 设计决策

1. 新增 `references/bulk-actions-batch-operations.md` 作为唯一 owner。
2. 用 `bulkActionState` 明确选择快照、范围绑定、目标集合、可执行性、确认策略、请求身份、部分结果、结果回执和恢复动作。
3. 强制区分当前页、已选择项、全部筛选结果、跨页集合和排除项集合。
4. 把危险批量动作、批量审批、批量导出、部分成功、权限无泄露分别转交已有 owner，避免重复定义。
5. 运行时未实际验证的浏览器、键盘、读屏、触摸、权限切换、弱网、异步任务和移动端场景必须标为未验证。

## 非目标

- 不定义后端批处理协议、队列、事务和重试算法。
- 不把单条编辑、列表内编辑或 spreadsheet-like 编辑矩阵纳入批量 owner。
- 不规定具体组件库、技术栈或业务字段。
