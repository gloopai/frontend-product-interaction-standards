# 搜索与命令面板交互规范

适用于全局搜索、全站搜索、站内搜索、命令面板、快速跳转、快捷搜索、动作搜索、对象搜索、搜索建议、最近搜索、保存搜索、搜索结果、结果分组、搜索预览、AI 搜索和自然语言搜索入口。本文件是搜索与命令面板交互、权限、安全、命令执行和验收的唯一事实来源。

列表、表格、报表或审计日志中的查询条件和筛选继续执行 [查询条件与筛选交互规范](query-filters.md)。字段 Select / Combobox 的内部搜索继续执行 [可搜索单选 Select / Combobox 交互规范](selects-comboboxes.md)。会修改数据、权限、导出、任务、密钥或外部系统的命令必须进入 [危险操作与恢复交互规范](risk-actions.md)。

普通列表关键词搜索、筛选栏搜索输入、局部搜索、页面内搜索、防抖搜索、搜索清空、搜索重置和 IME 搜索必须执行 `references/keyword-search-inputs.md`；本文件继续负责全局搜索、站内搜索页、命令面板、快速跳转、动作搜索、结果分组、命令执行和 AI 搜索。

顶部全局搜索入口、App Shell 搜索按钮、命令面板触发器和移动端搜索入口必须同时执行 `references/app-shell-navigation.md`；本文件负责搜索状态、结果和命令执行，`app-shell-navigation.md` 负责全局入口注册、权限可见性、当前上下文绑定和外框级焦点返回。

打开命令面板、快速跳转、动作搜索、结果激活或命令执行使用快捷键、热键、组合键或 keybinding 时，必须同时执行 `references/keyboard-shortcuts-commands.md`；本文件继续负责 `searchCommandState`、命令身份和结果执行，`keyboard-shortcuts-commands.md` 负责快捷键作用域、输入保护、冲突、可发现性、权限门禁和旧监听器清理。

涉及搜索结果激活后的返回、来源恢复或路由切换时，还必须执行 [导航与路由交互规范](navigation-routing.md)。涉及移动端、虚拟键盘、低高度、安全区域或跨端形态转换时，还必须执行 [响应式与自适应交互规范](responsive-adaptive.md)。兼容规则全部执行；一方更严格且不冲突时，执行更严格规则。

## 范围与边界

本 owner 覆盖：

- 顶部全局搜索、站内搜索页、全站搜索页、通用搜索入口和对象搜索。
- 命令面板、快捷命令、快速跳转、动作搜索、页面跳转和帮助命令。
- 搜索建议、最近搜索、保存搜索、结果分组、结果预览、搜索结果页和命令结果。
- 管理台中的租户/工作区、RBAC、审计、任务中心、导入导出、安全命令和跨页跳转。
- AI 搜索、自然语言搜索或语义搜索的交互边界、权限边界和未验证声明。

本 owner 不覆盖：

- 列表、表格、报表、审计日志或任务中心里的筛选条件区、筛选 chips、URL 筛选和筛选重置；这些由 `query-filters.md` 负责。
- 字段级 Select / Combobox / Autocomplete 的选项搜索、active option、popup、Drawer 和提交值；这些由 `selects-comboboxes.md` 负责。
- SQL/DSL 查询编辑器、复杂查询语言解析器、BI 自由分析器、搜索索引、搜索排序算法、向量检索服务或搜索引擎实现。

不得因入口里有“搜索”二字就把所有场景塞进一个 owner：列表内关键词筛选是查询条件；字段选项搜索是 Select；全局找对象、跳页面或执行命令才属于本 owner。

## `searchCommandState` 状态模型

每个搜索入口、全站搜索页或命令面板必须维护明确的 `searchCommandState`：

| 字段 | 语义 |
| --- | --- |
| `searchOwnerId` | 当前搜索入口、搜索页或命令面板的稳定身份。 |
| `surfaceKind` | `global-search`、`site-search`、`command-palette`、`quick-switcher`、`action-search`、`ai-search` 等承载类型。 |
| `queryDraft` | 用户正在输入、尚未提交的搜索草稿。 |
| `submittedQuery` | 已明确提交、用于结果请求、标题、URL、历史或来源恢复的查询。 |
| `resultSnapshot` | 本次结果的不可变快照，至少包含查询、权限版本、租户/工作区、数据范围、时间、来源和结果版本。 |
| `resultGroups` | 按对象、页面、命令、最近、保存、帮助、AI 建议等分组后的结果。 |
| `activeResult` | 键盘、指针或辅助技术当前指向的已渲染结果。 |
| `selectionState` | 已激活结果、已选择对象、待执行命令、参数补全或阻止原因。 |
| `commandBinding` | 命令身份、动作对象、风险等级、所需权限、参数、确认策略、请求身份和结果 owner。 |
| `permissionBoundary` | 搜索、展示、预览、跳转、历史、保存和命令执行各自的权限边界。 |
| `rankingPolicy` | 分组顺序、排序依据、置顶原因、最近/保存混排和可解释性策略。 |
| `historyPolicy` | 最近搜索、保存搜索、存储范围、清除路径、敏感查询、跨租户隔离和过期策略。 |
| `shortcutPolicy` | 打开快捷键、平台差异、冲突处理、禁用条件和替代入口。 |
| `feedbackState` | loading、empty、zero-results、partial、stale、error、permission-denied 和 recovery。 |
| `responsivePolicy` | 桌面、平板、移动端、Bottom Sheet、Drawer、全屏搜索页或独立页承载策略。 |
| `a11yPolicy` | 角色、名称、焦点、键盘、公告、状态说明、高对比度和 reduced motion。 |

搜索草稿、active result、hover suggestion 和最近搜索高亮不得触发导航、命令执行或请求副作用。只有明确提交搜索或激活结果后，才能改变导航、执行命令或写入已提交查询。

同一 `searchOwnerId` 内的请求、重试、防抖、快捷键监听、定位、焦点恢复、结果回调、历史写入和命令回执都必须绑定当前实例；旧实例、旧权限版本、旧租户/工作区或旧 `resultSnapshot` 的迟到回调只能丢弃，不能更新新实例。

## 草稿、提交和结果请求

输入 `queryDraft` 可以触发搜索建议请求，但建议请求和结果请求必须分离。建议不能写入 `submittedQuery`、URL、页面标题、结果摘要、最近搜索或来源上下文。

提交搜索必须来自明确动作：点击搜索按钮、按 Enter 提交当前查询、选择明确的“搜索此关键词”结果，或打开结果页时恢复安全 `submittedQuery`。IME 组合输入、hover、方向键移动、active result 变化、鼠标预览、最近搜索高亮和自动聚焦都不得提交。

每次提交搜索时创建新的 `resultSnapshot`，冻结 `submittedQuery`、租户/工作区、权限版本、数据范围、搜索来源、时间和请求身份。结果页、结果数量、URL、标题、历史、保存搜索和返回来源只读取 `submittedQuery` 与 `resultSnapshot`，不得读取仍在编辑的 `queryDraft`。

重复 Enter、重复点击搜索、请求重试或防抖回放必须使用幂等门禁；同一查询、同一权限版本和同一结果来源不得产生多个等价提交。权限、租户/工作区或搜索范围变化时，旧 `resultSnapshot` 立即失效。

## 建议、结果分组、预览和排序

结果分组必须声明来源、对象类型、排序依据、权限边界和可执行动作。对象结果、页面结果、命令结果、最近搜索、保存搜索、帮助结果和 AI 建议必须在视觉、语义和键盘路径上可区分。

搜索结果必须区分 loading、empty、zero-results、partial、stale、error 和 permission-denied。loading 不能清空旧结果后让用户误以为没有数据；partial 必须说明缺失范围和恢复路径；stale 必须说明过期原因；error 必须提供重试或安全退出；permission-denied 不得展示敏感对象信息。

结果预览不能替代结果激活。预览打开、hover、焦点移动或截断展开只展示当前结果的安全摘要，不得导航、执行命令、写历史或修改对象。预览内容必须复核权限和结果版本；过期或无权限时显示安全说明。

排序和置顶必须可解释。可以使用“最近访问”“高匹配”“常用命令”“管理员置顶”“收藏/保存”作为可读原因；不得把无权限、已删除或旧缓存结果混入排序。AI 或个性化排序不能泄露用户无权知道的对象存在。

## 命令面板、动作搜索和风险命令

命令结果必须声明命令身份、动作对象、所需权限、风险等级、是否需要参数、是否会离开页面、结果回执 owner、失败恢复和审计策略。

会修改数据、权限、导出、任务、密钥或外部系统的命令必须进入 `risk-actions.md`。这类命令在风险确认完成前请求数必须为 0；不得因为用户按 Enter、输入命令名称、hover 命令、命令排序第一或命令只有一个结果就直接发送请求。

安全跳转命令可以在激活后导航，但仍必须建立 `sourceContext` 并遵循 `navigation-routing.md`。需要参数的命令必须进入参数补全或表单承载；不得把 `queryDraft` 静默当作参数提交。

当 `activeResult` 不存在、结果未加载完成、结果过期、权限版本变化、命令参数缺失、对象不可见或风险确认未完成时，Enter 必须阻止执行，并给出可读反馈。禁用命令必须说明原因，不能只降低透明度或移除。

## 权限、租户/工作区和无泄露规则

搜索、建议、预览、结果展示、跳转、历史、保存搜索和命令执行各自都必须复核权限；不能把“搜索服务返回了”当成 UI 可展示授权。

无权限结果不得泄露对象名称、数量、字段、摘要片段、文件名、内部 ID 或旧缓存。权限降低、租户/工作区切换、角色变化、数据范围缩小或对象删除后，旧结果、旧建议、旧预览、旧最近搜索、旧保存搜索和旧命令参数必须隐藏、失效或替换为安全说明。

跨租户/工作区不得共享最近搜索、保存搜索、结果快照、命令参数或 AI 上下文，除非产品明确声明跨范围能力并逐项复核权限。管理台审计日志、权限页、任务中心、导入导出和密钥页必须把权限版本、租户/工作区和数据范围写入 `resultSnapshot` 或 `commandBinding`。

## 最近搜索、保存搜索、URL 和敏感查询

搜索历史、最近搜索和保存搜索必须声明存储范围、清除路径、权限复核和敏感查询策略。用户必须能找到清除最近搜索或删除保存搜索的路径；清除后不得通过刷新、返回、离线缓存或旧回调恢复。

敏感自由文本、个人识别信息、内部 ID、令牌、密钥、权限范围、租户内部名称、未公开对象名称和产品标记为敏感的查询不得进入 URL、页面标题、浏览器历史、analytics、日志、最近搜索或保存搜索。

只有明确 `urlSafe` 的 `submittedQuery` 和搜索结果页状态可以进入 URL。URL 恢复时必须校验版本、权限、租户/工作区和语法；无效、过期或无权限参数不能静默忽略，也不能伪装成成功结果，应显示可恢复状态。

保存搜索必须保存可复核的查询定义、显示名称、范围、创建人、权限策略和更新时间。保存搜索被重命名、删除、失权或定义过期时，入口必须显示安全状态和恢复路径。

## 键盘、焦点、快捷键和可访问性

搜索入口、命令面板和结果列表必须有可访问名称。打开后焦点进入搜索输入、标题或首个合理控件；关闭后返回触发入口；从结果导航到新页面时由 `navigation-routing.md` 建立新路由焦点。

键盘至少支持：打开快捷键、输入、上/下移动、Enter 激活、Escape 关闭或返回、Tab/Shift+Tab 焦点顺序、Home/End 跳到首尾结果。`activeResult` 只能指向已渲染、未禁用且权限合法的结果；虚拟列表必须确保 active 节点存在于 DOM。

打开快捷键不能与浏览器、输入法、编辑器、屏幕阅读器、系统快捷键或页面关键快捷键冲突；冲突时应禁用、改用显式入口或只在安全上下文启用。所有快捷键必须有可发现说明，不能成为唯一入口。

结果数量、loading、zero-results、partial、error、permission-denied、命令阻止和执行结果必须以可访问状态公告表达。颜色、图标、缩进、排序位置、hover 或 tooltip 不能成为唯一语义来源。

## 移动端承载和响应式转换

桌面端可使用顶部搜索框、居中 command palette、非模态建议面板或独立搜索页。移动端可使用全屏搜索页、Bottom Sheet、Drawer 或独立页，但移动端不得删除查询输入、提交、清空、结果分组、错误/权限说明、最近/保存搜索入口或恢复路径。

移动端有虚拟键盘时，搜索输入、清空、提交、关闭/返回、当前结果、错误说明和底部操作必须可达。Bottom Sheet 或 Drawer 形态必须执行 `drawers.md` 的遮罩、背景隔离、页面滚动锁、焦点陷阱、固定标题/关闭、内容区滚动、安全区域、遮罩点击不关闭、拖拽不关闭和 disposal 规则。

断点切换、旋转、动态视口、系统字体放大和 200% 缩放不得丢失 `queryDraft`、`submittedQuery`、结果快照、active result、命令参数、错误状态或权限说明。已打开实例转换形态时保持同一 `searchOwnerId`，不得重复请求、重复写历史、重复执行命令、重复遮罩、重复焦点陷阱或重复滚动锁。

触摸端不能依赖 hover、长按或精准拖拽发现结果、命令、预览或保存入口。每个核心动作必须有点击和键盘等价路径。

## AI / 自然语言搜索边界

AI / 自然语言搜索不得把建议答案、候选结果、可执行命令和已执行结果混为一谈。AI 输出必须明确是建议、摘要、候选结果、命令草案还是已执行结果。

AI 建议必须表达不确定性、来源、权限边界和恢复路径。AI 搜索不得在用户确认前静默执行命令、变更数据、发送导出、取消任务、重置密钥、修改权限或导航到敏感对象。

AI 摘要、语义匹配和推荐排序必须遵循同一权限边界：不得泄露无权限对象名称、数量、字段、摘要片段、文件名、内部 ID、旧缓存或跨租户上下文。AI 生成的命令参数必须由用户明确确认；风险命令仍必须进入 `risk-actions.md`。

## 生命周期、请求和清理

打开搜索或命令面板时，为当前实例登记请求控制器、防抖、重试、快捷键监听、结果回调、历史写入、焦点恢复、公告任务、预览浮层和命令回执。每项资源必须绑定 `searchOwnerId`、权限版本和租户/工作区。

关闭、路由变化、拥有组件卸载、租户/工作区切换、权限版本变化或搜索入口被替换时，当前实例立即进入 disposal：取消或失效旧请求、重试、防抖、快捷键监听、预览、公告、历史写入和命令回调；移除搜索 DOM、结果 DOM、预览 DOM 和 ARIA 引用；旧回调不得改变新实例、写入历史、执行命令或恢复到将被移除的旧焦点。

普通关闭可以按当前承载形态播放退出动画；disposal 不等待动画，也不执行旧触发器焦点恢复。每个实例只释放自己持有的资源，不能清理仍存活的 Dialog、Drawer、Select 或搜索实例。

## 完成前检查

- 验证搜索草稿、active result、hover suggestion、最近搜索高亮、预览打开和方向键移动都不会触发导航、命令执行、历史写入或请求副作用。
- 验证明确定交搜索后才更新 `submittedQuery`、结果请求、标题、URL、最近搜索和 `resultSnapshot`；重复 Enter 或重复点击不会生成多个等价提交。
- 验证结果分组必须声明来源、对象类型、排序依据、权限边界和可执行动作；对象结果、页面结果、命令结果、最近搜索、保存搜索、帮助结果和 AI 建议可区分。
- 验证搜索结果必须区分 loading、empty、zero-results、partial、stale、error 和 permission-denied，并提供对应恢复路径。
- 验证命令身份、动作对象、所需权限、风险等级、参数、确认策略、请求身份和结果 owner；风险命令、危险命令、权限变更、敏感导出、任务取消/重跑、密钥操作进入 `risk-actions.md`，确认完成前请求数为 0。
- 验证权限降低、租户/工作区切换、角色变化、数据范围缩小和对象删除后，无权限结果不得泄露对象名称、数量、字段、摘要片段、文件名、内部 ID 或旧缓存；旧建议、旧预览、旧历史和旧保存搜索被隐藏、失效或安全替换。
- 验证搜索历史、最近搜索和保存搜索必须声明存储范围、清除路径、权限复核和敏感查询策略；清除后刷新、返回、离线缓存或旧回调不能恢复。
- 验证 URL 只包含 `urlSafe` 的 `submittedQuery` 和结果页状态；敏感查询不进入 URL、标题、日志、analytics、最近搜索或保存搜索。
- 验证快捷键、输入、上/下移动、Enter、Escape、Tab/Shift+Tab、Home/End、焦点进入、焦点返回、状态公告和虚拟列表 active DOM。
- 验证移动端不得删除查询输入、提交、清空、结果分组、错误/权限说明、最近/保存搜索入口或恢复路径；全屏搜索页、Bottom Sheet、Drawer 或独立页均保留核心能力。
- 验证 AI / 自然语言搜索不得把建议答案、候选结果、可执行命令和已执行结果混为一谈；AI 建议表达不确定性、来源、权限边界和恢复路径，不静默执行命令。
- 验证关闭、路由变化、拥有组件卸载、租户/工作区切换和权限版本变化后的 disposal：旧请求、重试、防抖、快捷键监听、预览、公告、历史写入和命令回调全部取消或失效；旧回调不能改变新实例、写入历史、执行命令或恢复旧焦点。
- 真实浏览器、触摸、快捷键、搜索服务、AI 服务、权限切换和移动端视口未实际执行时，必须明确标为未验证，并列出所需验证。
