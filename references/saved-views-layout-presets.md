# 保存视图、视图预设与个性化布局交互规范

适用于后台、管理台、控制台、SaaS console 和内部工具中的保存视图、视图预设、我的视图、个人视图、共享视图、团队视图、默认视图、系统视图、收藏视图、保存筛选、筛选预设、列布局、列设置预设、布局预设、密度预设、恢复默认视图、设为默认视图、复制视图、共享筛选和视图切换器。

本文件是把当前已应用查询、筛选、排序、列布局、密度和展示模式冻结为可命名、可应用、可共享、可默认对象的唯一 owner。分页、页大小、排序、结果范围和结果摘要只能持久化 `references/list-result-controls.md` 中已提交且安全的结果控制，不能保存筛选草稿、搜索输入草稿、旧权限或旧结果；它不替代查询条件、数据表格、页面工具栏、权限、风险操作、审计日志或响应式 owner；当这些 owner 同时适用时，必须同时执行。

## 范围与非目标

本 owner 覆盖保存视图对象的身份、作用域、快照、应用、覆盖、删除、共享、取消共享、设为默认、恢复默认、复制视图、收藏视图、视图列表、权限收敛、结果回执、审计绑定和移动端承载。

本 owner 不定义表格列渲染、分页、排序算法、筛选字段内部交互、表单校验、具体组件库 API、后端存储协议、同步算法、协作编辑、推荐视图、跨产品模板市场或像素级样式。页面可以不支持保存视图；不支持时必须有 absence contract：DOM、state、handler、request、快捷键、缓存和旧入口均为 0，不能残留隐藏保存路径或旧视图缓存。

## `savedViewState`

每个支持保存视图、视图预设或布局预设的页面必须声明 `savedViewState`：

| 字段 | 语义 |
| --- | --- |
| `savedViewOwnerId` | 当前页面、列表、报表、看板或日志视图的稳定 owner 身份。 |
| `viewIdentity` | 视图 ID、名称、类型、来源、版本、创建人、更新时间、系统预设标记、收藏状态和当前是否正在应用。 |
| `viewScope` | 个人、团队、租户/工作区、角色、系统默认、共享范围、继承权限、外部成员可见性和可见权限。 |
| `appliedSnapshot` | 当前已应用查询、筛选、排序、时间范围、结果范围、URL 版本和展示上下文快照。 |
| `layoutSnapshot` | 可持久化的列可见性、列顺序、固定列、列宽、密度、展示模式、分组、卡片/表格模式和图表/表格模式。 |
| `draftBinding` | 当前筛选草稿、字段内部草稿、列调整草稿、命名草稿、共享设置草稿、默认设置草稿和覆盖确认草稿的边界。 |
| `defaultPolicy` | 系统默认、个人默认、团队默认、角色默认、恢复默认、默认冲突和默认优先级。 |
| `sharePolicy` | 可共享对象、共享范围、角色继承、字段可见性、敏感字段、外部成员和无泄露策略。 |
| `applyIntent` | 应用视图、覆盖视图、复制视图、删除视图、设为默认、取消共享、恢复默认和导入/导出视图的冻结意图。 |
| `permissionBoundary` | 查看、应用、保存、覆盖、删除、共享、设默认、恢复默认和审计所需权限版本、租户/工作区、角色和能力开关。 |
| `resultReceipt` | 成功、失败、部分成功、冲突、权限拒绝、未知、过期、已降级和恢复路径。 |
| `auditBinding` | 创建、覆盖、应用、共享、取消共享、设默认、恢复默认、复制和删除视图的审计身份、请求身份和查看入口。 |
| `responsivePolicy` | 桌面、平板、移动端、低高度、虚拟键盘、安全区域、Action Sheet、Drawer、Bottom Sheet 和独立页承载策略。 |

`savedViewState` 只能描述保存视图对象与跨 owner 快照的关系，不能把筛选字段、表格选择、分页状态、Dialog 状态或权限缓存复制成第二套事实来源。

## 保存快照与草稿边界

保存视图必须读取 `appliedSnapshot` 和明确允许持久化的 `layoutSnapshot`。筛选草稿、Select query、active option、未提交日期范围、正在编辑的列拖拽、当前临时页码、展开行、hover、高亮、焦点、loading、错误状态和旧结果缓存不得进入正式保存视图。

保存视图前必须明确“保存已应用条件”或要求用户先应用/确认草稿。若用户正在编辑筛选、日期范围、列设置、密度、展示模式或共享设置，保存操作只能读取已经提交的状态；不能悄悄应用草稿，也不能把草稿和已保存视图合并成一个状态。

视图名称、描述、收藏、共享范围和默认范围的编辑草稿属于 `draftBinding`。这些草稿在确认前不得改变 `viewIdentity`、`viewScope`、`defaultPolicy` 或 `sharePolicy` 中已生效的值。取消、Escape、遮罩关闭例外、路由离开和 owner disposal 都不得提交这些草稿。

当前页码、游标、滚动位置、当前行选择、跨页选择、展开行、打开菜单、当前焦点、临时错误、加载状态和旧结果缓存不是保存视图。若产品需要保存某种布局或展开偏好，必须明确写入 `layoutSnapshot` 的可持久化字段，并说明它不会改变查询结果、权限或业务提交。

## 应用视图与结果联动

应用视图必须创建 `applyIntent`，说明将替换哪些内容：查询、筛选、排序、时间范围、列布局、密度、展示模式、分组、报表图表配置、URL 状态、默认视图或当前视图标签。应用视图不是普通筛选重置，也不是普通列设置保存。

Query Filters、Data Table、Toolbar、URL、结果摘要和焦点必须读取同一视图版本。应用完成后，旧查询请求、旧结果、旧列布局、旧 URL、旧筛选摘要、旧导出范围、旧焦点任务、旧 live region 文案和旧 Toolbar 状态必须失效或重算。

应用视图前若存在未保存筛选草稿、未提交列设置、未完成异步任务、当前批量选择、未保存表单或正在编辑的记录，必须按对应 owner 处理离开、覆盖、选择失效或恢复确认。不得因为应用视图而静默丢弃用户草稿，也不得自动提交与视图无关的表单。

应用失败、权限拒绝、字段不可见、视图过期、版本冲突、部分降级或未知结果必须进入 `resultReceipt`，并提供刷新视图列表、检查当前视图、恢复默认、重试、查看审计或联系支持路径。Toast 可以辅助，但不能是唯一回执或唯一恢复路径。

## 个人、共享、团队与默认视图

个人视图、团队共享视图、系统预设、个人默认、团队默认和角色默认必须分开表达。设为默认必须说明影响范围；共享必须说明可见对象和权限继承；删除共享视图不得删除他人的个人副本；恢复默认必须说明恢复到系统默认、个人默认还是团队默认。

同名视图、复制视图、收藏视图、系统预设覆盖、团队默认冲突和角色默认冲突必须展示明确归属。不能用一个“默认”标签同时表示系统默认、个人默认和团队默认；不能用一个“共享”标签同时表示团队可见、角色可见和外部成员可见。

恢复默认是明确动作，不是清空视图列表。恢复默认必须说明将恢复哪些快照：筛选、排序、时间范围、列布局、密度、展示模式、分组或图表配置。恢复默认后，当前视图名称、已应用摘要、URL、结果 owner 和 Toolbar 必须进入同一默认版本。

系统预设和只读共享视图可以应用、复制或收藏，但不得覆盖或删除。无权覆盖或删除时，应提供安全原因和可用替代路径，例如复制为个人视图、申请权限或联系管理员。

## 覆盖、删除、共享与恢复默认

覆盖视图、删除视图、设为默认、共享给团队、取消共享、恢复默认和批量管理视图必须说明影响范围、视图版本、目标范围、权限版本、请求身份和未知结果。高影响动作必须进入 [危险操作与恢复交互规范](risk-actions.md)；确认前请求数为 0。

覆盖视图必须展示将被替换的视图名称、作用域、版本、最后更新时间和快照范围。覆盖个人视图不得影响团队默认；覆盖团队共享视图不得影响已复制的个人副本；覆盖系统预设默认应被禁止或进入更高权限流程。

删除视图必须区分删除个人视图、删除团队共享视图、取消共享和从我的收藏中移除。删除共享视图不得删除他人的个人副本；取消共享不得删除创建者自己的视图；移除收藏不得删除源视图。

共享视图必须展示共享对象、可见字段、筛选值、敏感字段处理、外部成员策略、权限继承和审计结果。取消共享、扩大共享范围、设为团队默认、覆盖团队视图和批量管理视图可能影响多人，应说明影响范围并保留审计回执。

未知结果不能伪装成已保存、已覆盖、已删除、已共享、已设为默认或已恢复默认。网络中断、权限竞态、版本冲突、审计不可用或服务端超时后，界面必须提供检查最新状态、刷新视图列表、查看当前视图版本、查看审计或重试路径。

## 权限、租户、字段可见性与旧视图失效

共享视图不得泄露无权限字段、筛选值、对象名称、数量、列名、内部 ID、成员、客户、文件名、金额、发票、密钥、审计字段或旧缓存。对无权用户，视图列表、视图名称、字段摘要、筛选摘要、分享对象、错误详情、审计跳转和搜索结果都必须执行权限收敛。

权限、租户/工作区、角色、字段可见性、功能开关或数据范围变化后，旧视图必须失效、过滤、降级或要求重新确认。旧视图中的无权列、无权筛选、旧租户对象、旧成员、旧客户、旧发票、旧密钥字段、旧审计字段和旧 URL 状态不得继续暴露或应用。

应用、保存、覆盖、删除、共享、取消共享、设默认、恢复默认、复制、收藏、导入和导出视图前，必须复核 `permissionBoundary`。只隐藏按钮不够；旧快捷键、旧菜单项、旧链接、旧 Toast、旧 Notification、旧 URL、旧缓存和旧请求回调也必须失效。

视图降级必须可解释：哪些字段被移除、哪些筛选失效、哪些布局无法应用、当前结果是否仍可信、如何恢复默认或联系管理员。不得把权限降级后的视图静默显示为空白，也不得把无权字段名称作为错误说明泄露。

## 移动端与响应式承载

移动端不得删除视图切换、当前视图说明、保存视图、覆盖视图、恢复默认、权限原因、冲突恢复、错误回执和审计入口。低频视图管理可以进入更多菜单、Action Sheet、Drawer、Bottom Sheet 或独立页，但必须保留名称、作用域、当前是否已应用、默认归属、共享范围、禁用原因和焦点返回。

移动端保存视图、覆盖视图、共享设置和设为默认可以拆成多步承载；但当前已应用摘要、保存对象、影响范围、确认按钮、取消路径、恢复默认、错误说明和权限说明仍必须可达。低高度、虚拟键盘、安全区域、系统字体放大、横屏、触摸长按、WebView 返回和浏览器 Back 后，当前视图名、保存/取消、应用/恢复、共享范围、错误说明和焦点返回仍必须可达。

断点切换时必须保持同一 `savedViewOwnerId`、当前 `viewIdentity`、`appliedSnapshot`、`layoutSnapshot`、`draftBinding`、`applyIntent` 和请求身份。不得因桌面视图切换器转移动端 Action Sheet 或 Drawer 而重复请求、重复保存、重复覆盖、丢失草稿、改变默认范围或清空错误。

移动端可以把复杂列布局、共享范围、默认策略和视图详情放到独立页；需要稳定 URL、刷新恢复、深链、多人协作或长时间编辑的视图管理必须使用独立页或全屏 Drawer，不能塞进短 Dialog 或临时 Bottom Sheet。

## 与其他 owner 的关系

- [查询条件与筛选交互规范](query-filters.md)：筛选字段、`filterDraft`、`appliedFilters`、URL 安全和字段错误归 Query Filters；本 owner 只保存已应用且已证明安全的筛选快照。
- [数据表格交互规范](data-tables.md)：列状态、排序、分页、选择、结果状态和批量范围归 Data Table；本 owner 只能保存可持久化布局快照，不能保存当前页码或当前选择冒充视图。
- [页面操作栏与列表工具栏交互规范](page-toolbars-actions.md)：视图切换器、列设置入口、密度入口和更多菜单收纳归 Toolbar；本 owner 负责视图对象、作用域、应用、保存、共享、默认和结果回执。
- [设置、偏好与配置页交互规范](settings-preferences-configuration.md)：若视图作为个人偏好存在，设置页仍负责草稿、保存、生效和默认值；本 owner 负责页面视图语义和查询/布局联动。
- [权限、租户与可见性交互规范](permissions-tenancy-visibility.md)：共享范围、字段可见性、旧视图降级、无泄露和旧缓存清理为基础规则。
- [危险操作与恢复交互规范](risk-actions.md)：覆盖、删除、共享、设默认、恢复默认、取消共享和批量管理视图的高影响确认与未知结果。
- [审计日志与操作历史交互规范](audit-log-activity-history.md)：视图创建、覆盖、应用、共享、取消共享、设默认、恢复默认、复制和删除的审计。
- [响应式与自适应交互规范](responsive-adaptive.md)：移动端视图切换、列设置、共享设置、默认设置和断点转换。

## 完成前检查

- 验证每个支持保存视图、视图预设或布局预设的页面声明 `savedViewState`、`savedViewOwnerId`、`viewIdentity`、`viewScope`、`appliedSnapshot`、`layoutSnapshot`、`draftBinding`、`defaultPolicy`、`sharePolicy`、`applyIntent`、`permissionBoundary`、`resultReceipt`、`auditBinding` 和 `responsivePolicy`。
- 验证保存视图只读取 `appliedSnapshot` 和允许持久化的 `layoutSnapshot`；筛选草稿、Select query、active option、未提交日期范围、当前页码、展开行、hover、高亮、焦点、loading、错误状态和旧结果缓存均不进入正式视图。
- 验证保存视图前若存在筛选或列设置草稿，界面明确“保存已应用条件”或要求先应用/确认草稿；保存动作不得自动应用草稿。
- 验证应用视图创建 `applyIntent`，并让 Query Filters、Data Table、Toolbar、URL、结果摘要和焦点读取同一视图版本；旧请求、旧结果、旧 URL、旧导出范围和旧焦点任务失效或重算。
- 验证个人视图、团队共享视图、系统预设、个人默认、团队默认和角色默认分开表达；共享、删除和恢复默认不会误影响错误范围。
- 验证共享视图不泄露无权限字段、筛选值、对象名称、数量、列名、内部 ID、成员、客户、文件名、金额、发票、密钥、审计字段或旧缓存。
- 验证权限、租户/工作区、角色、字段可见性、功能开关或数据范围变化后，旧视图失效、过滤、降级或要求重新确认。
- 验证覆盖视图、删除视图、设为默认、共享给团队、取消共享、恢复默认和批量管理视图说明影响范围、视图版本、目标范围、权限版本、请求身份和未知结果；高影响动作进入风险确认，确认前请求数为 0。
- 验证未知结果不会被写成已保存、已覆盖、已删除、已共享、已设为默认或已恢复默认，并提供刷新视图列表、检查当前视图、查看审计、重试或联系支持路径。
- 验证移动端不得删除视图切换、当前视图说明、保存视图、覆盖视图、恢复默认、权限原因、冲突恢复、错误回执和审计入口。
- 真实浏览器、真实移动端、屏幕阅读器、真实权限/租户切换、真实 URL 恢复、真实多人共享、真实默认冲突、真实审计写入和真实表格/筛选联动未执行时，必须明确标为未验证，并列出所需验证。
