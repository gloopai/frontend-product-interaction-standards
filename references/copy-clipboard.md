# 复制与剪贴板操作交互规范

适用于业务提供的复制按钮、图标按钮、菜单项和快捷操作，包括复制字段、复制值、复制文本、复制 ID、复制编号、复制错误编号、复制链接、复制邀请链接、复制下载链接、复制地址、复制 URL、复制配置、复制片段、复制命令、复制审计字段、复制数据、复制图片、复制脱敏值、复制真实值、一键复制、复制失败和系统剪贴板。本文件是通用复制动作、剪贴板能力、旧内容失效、结果回执、失败恢复、可访问性和移动端底线的 owner。

复制按钮的文案、图标按钮、loading、防重复和禁用原因读取 [按钮交互规范](buttons.md)；菜单中的复制项读取 [浮层菜单与提示交互规范](overlays-menus-tooltips.md)；字段展示、脱敏展示和只读详情读取 [信息展示与详情页交互规范](information-display.md)；密钥、令牌、凭证、Reveal 和一次性真实值复制读取 [密钥、令牌与敏感凭证交互规范](secrets-credentials.md) 并执行更严格规则；下载链接和结果产物复制读取 [导出、下载与结果产物交付交互规范](exports-downloads-artifacts.md)；审计字段复制读取 [审计日志与操作历史交互规范](audit-log-activity-history.md)；权限、租户/工作区和无泄露读取 [权限、租户与可见性交互规范](permissions-tenancy-visibility.md)；短反馈读取 [全局反馈与通知交互规范](global-feedback.md)；移动端和 WebView 读取 [响应式与自适应交互规范](responsive-adaptive.md)。兼容规则全部执行；一方更严格且不冲突时，执行更严格规则。

浏览器原生选择文本并复制不属于业务复制按钮，但页面不得把原生选择复制作为查看全文、下载、Reveal、权限说明或恢复路径的唯一方式。只要产品提供“复制”入口，就必须进入本 owner。

## 场景与状态模型

每个业务复制动作维护 `copyActionState`：

| 字段 | 语义 |
| --- | --- |
| `copyOwnerId` | 当前复制动作 owner 稳定身份，绑定按钮/菜单、来源 owner、请求、回执和清理。 |
| `copyIntent` | 用户本次复制意图，包含目标字段/对象、格式、范围、触发方式、请求身份和时间。 |
| `sourceBinding` | 来源 owner、展示快照、对象身份、字段身份、版本、租户/工作区和权限版本。 |
| `valuePolicy` | 复制真实值、脱敏值、安全摘要、链接、结构化片段、图片或文件引用的策略。 |
| `sensitiveBoundary` | 敏感级别、脱敏规则、是否允许复制真实值、是否需要重新认证和是否需要持久警示。 |
| `clipboardCapability` | 安全上下文、浏览器/系统权限、移动端桥、用户手势、可写类型和失败原因。 |
| `linkBinding` | 链接类型、有效期、目标对象、权限复核、租户/工作区、一次性/可撤销/过期策略。 |
| `resultReceipt` | `copy-ready`、`copying`、`copied`、`failed`、`denied`、`expired`、`stale` 或 `unknown`。 |
| `auditBinding` | 复制动作、主体、目标、权限版本、字段类型、敏感等级和结果的审计身份。 |
| `focusReturn` | 复制后焦点保持、失败恢复焦点、菜单关闭和移动端替代路径。 |
| `disposalState` | 权限、路由、对象、快照、链接或 owner 变化后的旧复制入口、回执和 ARIA 清理。 |

## CPY-SCOPE 范围与 owner 边界

| 规则 ID | 规则 |
| --- | --- |
| CPY-SCOPE-01 | 每个业务复制按钮、菜单项、图标按钮和快捷复制动作必须声明 `copyActionState`。 |
| CPY-SCOPE-02 | 本 owner 定义复制动作、内容来源、权限、剪贴板能力、回执、失败恢复、可访问性和移动端底线；是否允许复制某类业务对象由来源 owner 决定。 |
| CPY-SCOPE-03 | 密钥、令牌、凭证、Reveal 和一次性真实值复制执行 `secrets-credentials.md` 的更严格规则；下载链接复制执行 `exports-downloads-artifacts.md` 的权限和有效期规则；审计字段复制执行 `audit-log-activity-history.md` 的脱敏和追溯规则。 |
| CPY-SCOPE-04 | 不得把复制动作降级为本地 `writeText(value)` 小工具；复制的值、来源、权限、敏感边界和回执都必须有 owner。 |

对应验收：CPY-A1、CPY-A2。

## CPY-STATE 复制意图、当前快照和旧内容失效

复制必须绑定当前快照。每个业务复制按钮、菜单项或快捷动作都必须创建 `copyIntent`，并绑定 `sourceBinding`。复制前读取的是当前可见且已证明安全的展示快照，不得读取旧 DOM、旧缓存、旧请求结果、隐藏字段、旧权限字段、旧下载 URL、旧邀请链接或旧审计详情。

| 规则 ID | 规则 |
| --- | --- |
| CPY-STATE-01 | `copyIntent` 必须记录目标字段/对象、复制格式、范围、触发方式、请求身份、时间和用户可理解动作对象。 |
| CPY-STATE-02 | `sourceBinding` 必须绑定来源 owner、展示快照、对象身份、字段身份、版本、租户/工作区和权限版本。 |
| CPY-STATE-03 | 复制触发后若权限、租户/工作区、对象状态、字段版本、链接有效期、显示快照或 owner 已变化，本次复制必须失败为 `stale`、`expired`、`denied` 或 `unknown`，不能继续写入剪贴板。 |
| CPY-STATE-04 | 旧复制入口、旧菜单项、旧回执、旧 ARIA 引用、旧焦点任务和旧 DOM 属性在 owner disposal、路由卸载、权限变化、对象变化、链接过期或快照替换后必须失效或清理。 |

对应验收：CPY-A1、CPY-A3、CPY-A8。

## CPY-VALUE 脱敏值、真实值和敏感边界

复制脱敏值必须明确告诉用户复制的是脱敏值或安全摘要，不能误导用户以为复制了真实值。复制真实值必须由来源 owner 明确允许，并执行更严格规则。

| 规则 ID | 规则 |
| --- | --- |
| CPY-VALUE-01 | `valuePolicy` 必须区分真实值、脱敏值、安全摘要、链接、结构化片段、图片和文件引用。 |
| CPY-VALUE-02 | 真实值复制必须由来源 owner 明确允许；密钥、令牌和凭证真实值复制必须进入 `secrets-credentials.md`。 |
| CPY-VALUE-03 | 复制脱敏值、安全摘要或部分字段时，按钮文案、回执或说明必须表达复制内容类型，例如“复制脱敏邮箱”。 |
| CPY-VALUE-04 | Toast、Notification、Tooltip、ARIA label、审计摘要和错误说明不得包含真实密钥、token 片段、完整下载 URL、邀请 token、签名材料、payload、无权限字段或可复原敏感内容。 |
| CPY-VALUE-05 | 系统剪贴板、截图、录屏、键盘建议、共享设备或移动端系统分享面板风险需要提示时，说明必须持久、可访问且不包含真实值。 |

对应验收：CPY-A2、CPY-A5、CPY-A9。

## CPY-LINK 复制链接不是权限证明

复制链接不是权限证明。复制链接、复制下载链接、复制邀请链接、复制任务结果链接、复制审计跳转、复制 Webhook URL 或复制 deep link 时，链接本身不是长期授权。

| 规则 ID | 规则 |
| --- | --- |
| CPY-LINK-01 | `linkBinding` 必须说明链接类型、目标对象、有效期、权限复核、租户/工作区、一次性/可撤销/过期策略和旧链接失效路径。 |
| CPY-LINK-02 | 旧复制链接、旧浏览器历史、旧 Toast/Notification、旧菜单项和旧 DOM 属性必须在权限变化、会话过期、租户/工作区切换、对象删除、任务过期、文件过期、邀请撤销、凭证轮换或链接版本变化后失效或重新证明安全。 |
| CPY-LINK-03 | 复制链接成功不代表链接已授权、已发送、已被使用、文件可下载、邀请已送达或任务完成。 |
| CPY-LINK-04 | 无权限、过期、撤销或跨租户链接不得通过剪贴板、Toast、ARIA、浏览器历史或错误说明泄露目标名称、文件名、邀请对象、内部 ID、token 或旧 URL。 |

对应验收：CPY-A4、CPY-A8。

## CPY-RECEIPT 结果回执和失败恢复

复制成功只表示写入系统剪贴板成功，不代表用户已经安全保存、链接已经被使用、邀请已经发送、文件已经下载、任务已经完成、字段已经更新或审计已经导出。

| 规则 ID | 规则 |
| --- | --- |
| CPY-RECEIPT-01 | `resultReceipt` 必须区分 `copy-ready`、`copying`、`copied`、`failed`、`denied`、`expired`、`stale` 和 `unknown`。 |
| CPY-RECEIPT-02 | 回执应表达“已复制 X 的 Y”，但不得泄露敏感值、完整链接、token、密钥片段、payload 或无权限对象信息。 |
| CPY-RECEIPT-03 | 复制失败不能静默吞掉，也不能只让按钮闪一下。 |
| CPY-RECEIPT-04 | 复制失败必须说明可恢复原因：浏览器不支持、非安全上下文、系统剪贴板权限拒绝、移动端桥失败、内容已过期、权限变化、对象不可用、值不可复制或需要重新认证。 |
| CPY-RECEIPT-05 | 失败恢复必须提供重试、手动选择、下载、Reveal、重新生成、重新认证、查看安全说明或联系支持等适用路径。 |

对应验收：CPY-A5、CPY-A8。

## CPY-A11Y 可访问性、焦点和公告

复制按钮、图标按钮、菜单项和快捷操作必须有动作对象和可访问名称，例如“复制用户 ID”“复制发票下载链接”“复制脱敏邮箱”。不能只叫“复制”或只靠图标、Tooltip、Hover、颜色表达。

| 规则 ID | 规则 |
| --- | --- |
| CPY-A11Y-01 | 复制入口必须有可访问名称和动作对象；图标按钮不能只依赖 Tooltip 作为唯一名称。 |
| CPY-A11Y-02 | 复制成功、失败、权限拒绝、过期和未知结果必须由唯一 owner 公告，不能在按钮、Toast、Alert、Tooltip 和 live region 中重复播报同一完整消息。 |
| CPY-A11Y-03 | 焦点默认保持在触发控件；失败恢复需要移动焦点时，只能移动一次到错误说明、可重试按钮或安全替代目标。 |
| CPY-A11Y-04 | 菜单中复制后是否关闭菜单必须按菜单 owner 声明；失败时不能因菜单自动关闭而吞掉错误和恢复路径。 |
| CPY-A11Y-05 | 键盘、触摸、指针和辅助技术触发同一复制动作时，读取同一个 `copyIntent` 与 `sourceBinding`。 |

对应验收：CPY-A6、CPY-A9。

## CPY-PERM 权限、安全和审计

复制动作必须执行当前权限、租户/工作区、会话、对象状态和来源 owner 的安全边界。只有当前 `sourceBinding` 证明可见且 `valuePolicy` 允许的内容才能复制。

| 规则 ID | 规则 |
| --- | --- |
| CPY-PERM-01 | 无权限用户不得通过复制按钮、禁用原因、回执、错误、DOM、ARIA、浏览器历史、剪贴板内容或审计摘要推断对象名称、字段值、数量、文件名、链接、token、内部 ID、payload 或旧缓存。 |
| CPY-PERM-02 | 权限、租户/工作区、会话、对象状态、字段版本、链接版本或来源 owner 变化后，旧复制按钮、旧复制菜单、旧链接、旧真实值、旧脱敏状态、旧回执和旧审计跳转必须失效或重算。 |
| CPY-PERM-03 | 复制动作是否写审计由来源 owner 和敏感等级决定；审计不得包含真实密钥、完整 token、可复原片段、完整下载 URL、邀请 token、签名材料、payload 或剪贴板内容。 |
| CPY-PERM-04 | 需要重新认证的复制动作在认证完成前剪贴板写入数为 0；认证完成后仍须复核当前用户、权限版本、租户/工作区、对象状态和复制意图。 |

对应验收：CPY-A7、CPY-A8。

## CPY-RSP 移动端、WebView 和系统剪贴板

移动端、低高度、虚拟键盘、安全区域、WebView、系统分享面板、系统剪贴板限制和 200% 缩放下，不得删除核心复制入口、复制失败原因、敏感警示、权限说明或替代路径。

| 规则 ID | 规则 |
| --- | --- |
| CPY-RSP-01 | 移动端不得把复制入口只放在 hover tooltip、右键菜单、精确鼠标目标或不可达的表格列中。 |
| CPY-RSP-02 | 系统剪贴板不可用时，可以提供选择文本、下载文件、分享面板、二维码、重新生成链接或手动复制面板，但必须说明安全边界，并保证不会暴露无权限或过期内容。 |
| CPY-RSP-03 | WebView、系统分享面板和移动端原生桥失败时，必须返回当前页面的可恢复状态，不得丢失来源上下文、焦点或错误说明。 |
| CPY-RSP-04 | 虚拟键盘、安全区域、系统字体放大和 200% 缩放不得遮挡复制按钮、失败说明、敏感警示、重试或替代路径。 |

对应验收：CPY-A9。

## 可执行验收检查

下列检查以复制状态、DOM/ARIA、权限快照、链接有效期、剪贴板能力、焦点轨迹、结果回执和审计记录断言；未实际执行时必须报告为**未验证**并说明所需环境。

1. **状态模型**：记录 `copyActionState`，断言 `copyOwnerId`、`copyIntent`、`sourceBinding`、`valuePolicy`、`sensitiveBoundary`、`clipboardCapability`、`linkBinding`、`resultReceipt`、`auditBinding`、`focusReturn` 和 `disposalState` 均存在。
2. **当前快照**：打开详情、列表、菜单、审计详情和导出结果后复制字段；随后切换权限、租户/工作区、对象状态、字段版本或显示快照；断言旧 DOM、旧缓存、旧请求结果、隐藏字段、旧权限字段、旧下载 URL、旧邀请链接和旧审计详情不能写入剪贴板。
3. **值策略**：分别复制真实值、脱敏值、安全摘要、链接、结构化片段、图片和文件引用；断言文案、回执和审计明确表达复制类型，脱敏值不会被误认为真实值，真实值复制执行来源 owner 的更严格规则。
4. **链接安全**：复制下载链接、邀请链接、任务结果链接、审计跳转、Webhook URL 和 deep link；断言 `linkBinding` 有目标、有效期、权限复核、租户/工作区、一次性/可撤销/过期策略。权限、会话、租户、对象、任务、文件、邀请或凭证版本变化后，旧复制链接失效或重新证明安全。
5. **回执和失败恢复**：构造复制成功、浏览器不支持、非安全上下文、剪贴板权限拒绝、移动端桥失败、内容过期、权限变化、对象不可用、值不可复制、需要重新认证和未知结果；断言失败不静默，回执不泄露值，复制成功不伪装业务完成，并提供适用恢复路径。
6. **可访问入口**：检查复制按钮、图标按钮、菜单项和快捷操作的可访问名称、动作对象、键盘触发、焦点保持和菜单关闭语义；断言不能只叫“复制”，也不能只依赖 Tooltip、Hover、颜色或图标。
7. **权限和审计**：在复制前、复制中、复制后切换权限、租户/工作区、会话和对象状态；断言旧复制入口、旧回执、旧审计跳转和旧 ARIA 引用失效。需要审计的复制动作写入允许字段，不写真实密钥、完整 token、完整下载 URL、邀请 token、签名材料、payload 或剪贴板内容。
8. **disposal 和迟到结果**：路由卸载、owner disposal、上层弹层关闭、菜单关闭和来源对象移除后交付迟到复制成功/失败回调；断言旧回调不能更新新实例、不能聚焦已移除 trigger、不能留下旧 live region 或旧回执。
9. **移动端和运行时报告**：在移动端、WebView、系统分享面板、系统剪贴板限制、低高度、虚拟键盘、安全区域、系统字体放大和 200% 缩放下验证核心复制入口、失败原因、敏感警示、权限说明和替代路径。浏览器、移动端设备、WebView、系统剪贴板权限、屏幕阅读器、真实链接有效期、真实权限切换、真实重新认证、真实系统分享面板和真实审计写入未执行时，必须标为**未验证**。
