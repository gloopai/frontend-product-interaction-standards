# 信息展示与详情页交互规范

本文件是详情页、对象详情、信息展示、描述列表、Key-Value List、只读字段、信息卡、摘要卡、指标卡、状态标签、状态徽标、元数据、基础信息、复制字段、脱敏展示和长文本展示的唯一 owner。

信息展示不是“把接口字段摆出来”。每个展示区域必须说明它展示的对象是谁、字段含义是什么、值从哪个快照来、用户是否有权看到、数据是否新鲜，以及相关操作读取的是哪份展示快照。

详情折叠、只读字段分组、展开/收起区块、错误详情折叠和移动端折叠内容必须同时执行 `references/disclosure-accordions.md`；本文件继续负责字段语义和只读展示，折叠 owner 负责展开状态、错误外显、权限摘要和焦点路径。

从列表、表格、卡片列表、搜索结果或报表明细进入的详情预览、侧边预览、行预览、记录预览、快速查看、只读预览和 Master-Detail 必须同时执行 `references/preview-pane.md`；本文件负责预览内字段 label/value、空值、状态、复制和长文本展示，`preview-pane.md` 负责预览目标、来源绑定、关闭返回、迟到响应、权限无泄露和移动端承载边界。

只读字段 label、详情字段说明、单位、格式示例、来源说明、空值说明、权限原因、只读原因、禁用原因和 Tooltip 帮助必须同时执行 `references/field-guidance-help-text.md`；本文件继续负责展示对象、字段值、展示快照和只读布局，`field-guidance-help-text.md` 负责说明语义、placeholder 禁止替代、帮助可达性和旧描述引用清理。

概览页、仪表盘首页、管理台首页、运营看板、业务看板、指标总览、报表总览和 dashboard landing 的 KPI、摘要卡、指标卡和状态摘要必须同时执行 `references/overview-dashboard-pages.md`；本文件负责字段口径和只读展示，`overview-dashboard-pages.md` 负责页面级 `dataSnapshot`、`timeRangeSnapshot`、模块一致性和移动端总览保留。

## 状态模型

每个详情页或信息展示区域必须声明 `informationDisplayState`，至少包含：

| 字段 | 要求 |
| --- | --- |
| `displayOwnerId` | 展示区域 owner；页面标题、详情主体、指标卡和侧栏摘要可拆成多个 owner，但不能共用隐式全局展示状态。 |
| `subjectIdentity` | 被展示对象的类型、身份、安全可见名称、租户/工作区和权限版本。 |
| `displaySnapshot` | 字段值、指标值、状态值、来源数据版本、刷新时间和数据延迟。 |
| `fieldSemantics` | 字段 label、值类型、单位、格式、空值策略、帮助说明、来源说明和敏感边界。 |
| `visibilityPolicy` | 字段或区块的可见、脱敏、只读、无权限、条件可见、已删除、不适用或不可用策略。 |
| `freshnessState` | `loading`、`fresh`、`stale`、`refresh-error`、`partial`、`unknown` 或 `permission-denied`。 |
| `statusSemantics` | 状态 key、状态文案、严重度、颜色/图标辅助、来源、刷新时间、适用时间和下一步。 |
| `actionBinding` | 复制、跳转、编辑、导出、刷新、重试或危险操作绑定的对象快照、权限和结果 owner。 |
| `copyPolicy` | 允许复制字段、复制格式、脱敏规则、权限复核和复制回执。 |
| `responsivePolicy` | 移动端分组、折叠优先级、固定摘要、不可隐藏信息和触摸路径。 |
| `a11yPolicy` | 区域名称、字段名称和值关联、状态说明、键盘路径、展开/复制说明和公告策略。 |
| `auditBinding` | 创建人、创建时间、更新人、更新时间、操作人、请求身份、审计入口和追溯状态。 |

## 原子规则

| ID | 规则 |
| --- | --- |
| IDS-SCOPE-01 | 详情页、对象详情、信息展示、描述列表、Key-Value List、只读字段、信息卡、摘要卡、指标卡、状态标签、状态徽标和元数据展示必须归属 `informationDisplayState`。 |
| IDS-SCOPE-02 | 信息展示 owner 只负责用户看到的信息是否准确、可解释、可追溯、安全；字段编辑、危险确认、路由返回、查询筛选和图表编码仍归对应 owner。 |
| IDS-SCOPE-03 | 详情页、描述列表、指标卡和信息卡必须声明展示对象、数据来源、权限版本、刷新状态和数据延迟。 |
| IDS-SCOPE-04 | 同一对象的标题、主状态、基础信息、指标摘要、审计摘要和操作区读取不同快照时，必须可见说明差异。 |
| IDS-SCOPE-05 | 只读展示区中的操作入口必须显式声明动作对象、权限、结果 owner 和目标承载面。 |
| IDS-READONLY-01 | 详情页不得直接内嵌 input、textarea、select、可编辑表格或行内保存按钮来完成编辑。 |
| IDS-READONLY-02 | 只读状态不得用 disabled 表单控件充当展示文本；只读展示必须使用文本、描述列表、代码块、标签、卡片或专用只读组件。 |
| IDS-READONLY-03 | 新增、编辑、复制创建、配置和批量配置必须进入 `record-editing-surfaces.md` 规定的 Dialog、Drawer 或独立页。 |
| IDS-READONLY-04 | 如果详情页存在“编辑”入口，入口必须说明编辑对象、权限状态、目标承载面和返回策略；不得让只读字段原地变成可编辑字段。 |
| IDS-READONLY-05 | 只读权限和无编辑权限必须可理解；不得只把按钮隐藏或 disabled，而不说明原因和允许的下一步。 |
| IDS-FIELD-01 | 每个字段必须有明确 label、值、单位、格式、帮助说明或来源说明；不得只展示裸值。 |
| IDS-FIELD-02 | 空值、未配置、未知、加载失败、无权限、已删除和不适用必须可区分；不得统一显示 `-`、空字符串或 `N/A`。 |
| IDS-FIELD-03 | 金额、数量、比例、容量、时长、日期时间、时区、状态、权限范围和版本号必须展示单位或格式规则。 |
| IDS-FIELD-04 | ID、密钥、邮箱、手机号、文件名、路径、URL、金额和权限字段必须声明脱敏、复制和展示格式。 |
| IDS-FIELD-05 | 字段帮助说明、来源说明和错误/权限说明不能只放在 hover tooltip；触摸和键盘路径也必须可达。 |
| IDS-STATUS-01 | 状态标签、徽标、颜色、图标和趋势箭头不能是唯一语义来源。 |
| IDS-STATUS-02 | 状态必须包含文本、严重度、来源、刷新时间或适用时间，并在需要用户行动时提供下一步。 |
| IDS-STATUS-03 | 风险、失败、部分成功、未知结果、权限降级、过期、冲突和数据延迟必须接入对应 owner，不得只展示一个状态标签。 |
| IDS-STATUS-04 | 多个状态同时存在时，必须声明主状态、次状态、风险状态和阻塞状态的优先级；不得用最后一个接口字段覆盖全部状态。 |
| IDS-STATUS-05 | 状态变化必须绑定 `displaySnapshot`，迟到响应不得把旧状态写成当前状态。 |
| IDS-METRIC-01 | 指标卡必须声明指标名、口径、单位、时间范围、数据延迟、刷新时间和权限范围。 |
| IDS-METRIC-02 | 指标为 0、空、无权限、未产生、计算失败和数据延迟必须分开展示。 |
| IDS-METRIC-03 | 指标卡默认只读；选择、钻取、导出、刷新和跳转能力必须显式声明。 |
| IDS-METRIC-04 | 指标卡、图表、明细表和导出任务共享同一范围时，必须展示同一快照来源；不得各自重新计算。 |
| IDS-METRIC-05 | 趋势、同比、环比和排名必须声明比较对象、时间范围、方向含义和数据延迟。 |
| IDS-ACTION-01 | 复制、打开详情、编辑、导出、删除、停用、启用、归档、刷新和重试按钮必须绑定当前展示快照。 |
| IDS-ACTION-02 | 复制操作不得复制脱敏或无权限字段的真实值，且需要可感知回执。 |
| IDS-ACTION-03 | 危险操作必须进入 `risk-actions.md`；编辑入口必须进入 `record-editing-surfaces.md`；按钮语义必须进入 `buttons.md`。 |
| IDS-ACTION-04 | 操作入口不得只出现在 hover、右键菜单、Tooltip 或不可发现的图标里；至少有一个键盘和触摸可达路径。 |
| IDS-ACTION-05 | 操作完成后的结果回执必须能回到展示区、任务中心或审计入口；Toast 不能作为唯一回执。 |
| IDS-PERM-01 | 无权限展示不得泄露对象名称、字段值、数量、文件名、内部 ID、筛选值或旧缓存。 |
| IDS-PERM-02 | 权限降级、租户切换、对象删除、角色变化或数据范围变化后，旧详情字段、旧标题、旧状态和旧操作入口必须重新证明安全。 |
| IDS-PERM-03 | 脱敏值必须标注脱敏状态；复制、导出、跳转和审计入口必须复核权限。 |
| IDS-PERM-04 | 条件可见字段必须说明隐藏原因属于无权限、不适用、未配置、对象类型不支持还是数据尚未产生。 |
| IDS-PERM-05 | 只读详情页不得用旧缓存维持用户已经失去权限的敏感字段。 |
| IDS-LAYOUT-01 | 字段分组必须按任务语义组织，不得只按接口返回顺序铺开。 |
| IDS-LAYOUT-02 | 长文本、代码、JSON、URL、邮箱、文件名和路径必须有换行、展开、复制和溢出策略。 |
| IDS-LAYOUT-03 | 重要字段不能只放在 hover tooltip、popover、更多菜单、右侧隐藏区域或低可见折叠区。 |
| IDS-LAYOUT-04 | 页面标题、对象身份、主状态、关键指标、权限说明和主要操作应在详情页进入后快速可见。 |
| IDS-LAYOUT-05 | 描述列表多列布局在窄屏重排时必须保持 label-value 关联，不得把值排到错误 label 下。 |
| IDS-RSP-01 | 移动端可以把描述列表变成卡片、分组、Accordion、Tabs 或独立区块。 |
| IDS-RSP-02 | 折叠默认态必须保留对象身份、主状态、关键指标、风险/错误、权限说明、刷新/延迟和主要操作入口。 |
| IDS-RSP-03 | 移动端不得删除字段 label、单位、状态说明、错误/权限说明、复制/恢复路径或审计入口。 |
| IDS-RSP-04 | 横向字段、长 ID、代码、JSON、URL 和路径在移动端必须可阅读、可复制且不撑破布局。 |
| IDS-RSP-05 | 固定页头、底部操作、Tabs、Accordion 和安全区域不得遮挡当前字段、状态说明或主要操作。 |
| IDS-A11Y-01 | 详情区域、信息卡、指标卡、状态区和操作组必须有可访问名称。 |
| IDS-A11Y-02 | 字段 label 与值必须在读屏中保持关联；状态不能只靠颜色、位置或图标表达。 |
| IDS-A11Y-03 | 可复制字段、展开长文本、跳转链接和操作按钮必须可键盘访问，并有清晰动作对象。 |
| IDS-A11Y-04 | 状态变化、刷新失败、权限降级、部分结果和复制成功/失败必须由唯一 owner 公告，避免重复播报。 |
| IDS-A11Y-05 | 指标卡必须可被读屏理解为指标名、数值、单位、时间范围、比较对象和状态。 |
| IDS-LIFE-01 | 展示区刷新前后必须保留旧内容、标记 stale 或 loading 策略，不得闪成空白误导用户。 |
| IDS-LIFE-02 | 迟到响应只能写回匹配 `displaySnapshot` 和权限版本的展示区。 |
| IDS-LIFE-03 | 详情页卸载、Tabs 切换、权限变化或断点转换时，必须清理仅属于该展示 owner 的监听、复制回执、展开状态和刷新请求。 |
| IDS-LIFE-04 | 从详情进入编辑、导出或危险确认时，必须冻结当前展示快照；返回后若快照过期，展示 stale 或重新加载。 |
| IDS-LIFE-05 | 未执行真实浏览器、读屏、触摸、缩放、刷新、权限切换和真实数据检查时，必须标为未验证。 |

## 场景化要求

### 详情页与对象身份

- 页面标题必须能让用户确认当前对象，但权限不足时只能使用安全可见名称或泛化说明。
- 主状态、关键属性、权限说明和主要操作入口应在首屏或首个详情区可见。
- 从列表、报表、通知或外链进入详情时，返回和来源恢复读取 `navigation-routing.md`。

### 描述列表与只读字段

- 字段 label 不能省略；相邻字段、分组标题和单位必须帮助用户理解值的含义。
- `0`、`false`、空数组、未配置、无权限和加载失败是不同状态；文案和可访问说明必须区分。
- 只读字段需要复制时，复制按钮必须说明复制对象，并按 `copyPolicy` 处理脱敏和权限。

### 状态标签和状态摘要

- 状态标签必须有文本，颜色和图标只能辅助。
- 如果状态代表失败、风险、过期、部分成功、未知结果或权限问题，必须提供原因、影响和下一步。
- 状态摘要和详情字段冲突时，必须显示数据版本或刷新状态，不能静默展示互相矛盾的信息。

### 指标卡和概览卡

- 指标卡必须展示指标名、数值、单位、口径、时间范围、数据延迟、刷新时间和权限范围。
- 指标点击钻取、导出或刷新时，必须绑定当前 `displaySnapshot`；不能读取已改变但未展示的筛选或时间范围。
- 指标异常、无数据、无权限和计算失败必须进入反馈状态 owner，不能只显示灰色数字或空卡片。

### 权限、脱敏与复制

- 无权限时不能保留旧字段值、旧标题、旧状态、旧复制内容或旧下载入口。
- 脱敏值必须让用户知道它被脱敏；复制结果不能绕过脱敏。
- 审计入口和下载入口必须基于当前权限版本复核。

### 移动端展示

- 详情页可以重排为卡片、分组、Accordion 或 Tabs，但默认态必须保留对象身份、主状态、关键指标、风险/错误、权限说明、刷新/延迟和主要操作入口。
- 折叠内容必须有清晰标题、数量或摘要；不能把错误、权限说明、审计入口或恢复路径藏到用户无法发现的位置。
- 长文本、代码、JSON、URL、邮箱、文件名和路径必须可阅读、可复制且不撑破布局。

## 完成前检查

1. 是否声明 `informationDisplayState` 及全部必要字段。
2. 详情页是否没有直接内嵌 input、textarea、select、可编辑表格或行内保存按钮来完成编辑。
3. 只读状态是否没有用 disabled 表单控件冒充展示文本。
4. 空值、未配置、未知、加载失败、无权限、已删除和不适用是否可区分。
5. 状态标签、颜色、图标和趋势箭头是否不是唯一语义来源。
6. 指标卡是否声明指标名、口径、单位、时间范围、数据延迟、刷新时间和权限范围。
7. 复制、导出、跳转、编辑和危险操作是否绑定当前展示快照与权限版本。
8. 无权限、脱敏、权限降级和旧缓存是否不会泄露敏感信息。
9. 移动端是否保留字段 label、单位、状态说明、错误/权限说明、复制/恢复路径和审计入口。
10. 未实际执行运行时检查时，是否明确标为未验证。
