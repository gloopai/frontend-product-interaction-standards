# 卡片列表与卡片式结果交互规范

适用于卡片列表、卡片式结果、资源卡片、模板卡片、应用卡片、内容卡片、项目卡片、卡片网格、移动端结果卡片和 Kanban-lite 列表。

本文件是“以卡片作为主要结果形态”的唯一 owner。若结果本质是数据表格，只是在窄屏或 200% 缩放后转换为卡片，仍以 `references/data-tables.md` 为主，本文件只补充卡片结构、交互区域和移动端可达性。查询、排序、分页、刷新、结果摘要和总数可信度读取 `references/list-result-controls.md`；人工排序、拖拽排序、卡片重排、上移/下移、置顶/置底和保存顺序读取 `references/ordering-reordering.md`，本文件只提供排序入口和卡片身份。页面工具栏和视图切换读取 `references/page-toolbars-actions.md`；按钮读取 `references/buttons.md`；更多菜单、Dropdown、Popover 和 Action Sheet 读取 `references/overlays-menus-tooltips.md`；详情预览读取 `references/preview-pane.md`；新增、编辑、复制创建和字段保存读取 `references/record-editing-surfaces.md`；权限读取 `references/permissions-tenancy-visibility.md`；反馈状态读取 `references/feedback-states.md`；响应式读取 `references/responsive-adaptive.md`。

卡片列表不是营销卡片墙。它是管理台结果 surface，必须能回答：每张卡片代表哪个记录、哪些字段直接可见、哪些字段可展开、哪些动作可执行、哪些能力被禁用或隐藏、数据是否新鲜、用户是否有权看到和操作。

## 范围与排除项

本 owner 覆盖记录型卡片结果、资源库卡片、模板卡片、应用卡片、项目卡片、内容卡片、配置项卡片、移动端结果卡片、轻量 Kanban 列和非表格主结果卡片。

本 owner 不覆盖营销落地页卡片、纯装饰卡片、静态宣传卡片、图表卡片、指标卡、表格单元格、复杂看板拖拽工作流、日历、时间线或文件媒体播放器。图表卡与指标卡读取各自 owner；文件媒体渲染读取 `files-media-assets.md`。

## `cardListResultState`

每个卡片列表实例必须声明 `cardListResultState`，至少包含：

| 字段 | 语义 |
| --- | --- |
| `cardListOwnerId` | 当前卡片列表稳定 owner；不得复用页面、表格、卡片 DOM ID 或当前数组索引。 |
| `surfaceKind` | `grid`、`list`、`masonry-forbidden`、`kanban-lite`、`mobile-card-list` 或产品声明的卡片形态。 |
| `capabilityTier` | `display`、`item-action` 或 `selection-action`。 |
| `sourceBinding` | 已应用查询、排序、分页/游标、结果版本、权限范围、来源 owner 和当前视图配置。 |
| `cardIdentityMap` | 每张卡片的稳定记录 ID、对象类型、安全可见名称、租户/工作区、权限版本和资源版本。 |
| `fieldMapping` | 标题、副标题、主状态、关键指标、缩略图、元数据、次要字段、可展开字段、不可隐藏字段、空值和脱敏策略。 |
| `interactionZones` | 打开详情区、选择区、操作区、复制区、菜单区、预览入口和拖拽/排序禁用边界。 |
| `selectionBinding` | 卡片选择、全选、批量范围、不可选原因、排除项、选择代次和批量工具栏绑定。 |
| `actionBinding` | 单卡片操作、批量操作、危险操作、编辑入口、预览入口、复制入口和结果 owner。 |
| `requestBinding` | 结果请求代次、卡片数据快照、迟到响应、刷新、stale、partial 和 disposal 门禁。 |
| `permissionBoundary` | 标题、封面、缩略图、数量、标签、状态、字段、文件名、菜单、错误、旧缓存和 ARIA label 无泄露边界。 |
| `feedbackBinding` | loading、empty、zero-results、refresh-error、stale、partial、permission-denied 和恢复入口。 |
| `responsivePolicy` | 列数、最小宽度、断点、触摸目标、200% 缩放、虚拟键盘、安全区域、低高度和长文本策略。 |
| `focusKeyboardPolicy` | 卡片整体、内部控件、菜单、选择、详情、预览和断点转换的键盘与焦点策略。 |
| `runtimeVerification` | 真实浏览器、键盘、读屏、触摸、断点、权限切换和真实数据竞态验证状态；未执行必须标为未验证。 |

不得只用 `cards`、`items`、`selectedIds`、`gridView`、`viewMode`、`cardProps` 或组件库 Masonry/Grid 状态替代 `cardListResultState`。

## 能力档位

`capabilityTier` 只能是 `display`、`item-action` 或 `selection-action`。

| 规则 ID | 规则 |
| --- | --- |
| `CLR-CAP-01` | `display` 只展示、筛选、排序、分页、刷新、打开详情或预览；不得渲染选择控件、批量工具栏、隐藏选择状态或批量请求入口。 |
| `CLR-CAP-02` | `item-action` 可以提供单卡片操作、复制、打开详情、详情预览和更多菜单，但不得自动获得多选、全选或批量能力。 |
| `CLR-CAP-03` | 只有 `selection-action` 可以渲染选择与批量操作；选择范围、不可选原因、排除项、批量确认和部分成功继续执行数据表格/风险操作相关 owner。 |
| `CLR-CAP-04` | 权限降级可以降低档位；降级时必须移除越权 DOM、state、handler、request 和旧焦点目标，不能只灰掉按钮或留下空批量工具栏。 |

## 卡片结构与字段映射

卡片必须有稳定结构，不能按接口字段顺序随手堆。

| 规则 ID | 规则 |
| --- | --- |
| `CLR-STRUCT-01` | 每张卡片必须有记录级可访问名称，名称来自当前权限证明安全的记录身份。 |
| `CLR-STRUCT-02` | 字段必须通过 `fieldMapping` 显式声明 label、值、单位、状态、空值、脱敏、可复制、优先级和移动端展示策略。 |
| `CLR-STRUCT-03` | 记录身份、主状态、风险/错误、权限原因、关键指标或主要下一步不得只放在封面图、tooltip、hover、颜色、图标、截断文本或隐藏菜单里。 |
| `CLR-STRUCT-04` | 卡片列表不得启用不可预测 Masonry 排布承载关键结果；`masonry-forbidden` 表示高度不一内容只能自然排布，不得让键盘顺序、阅读顺序和视觉顺序互相矛盾。 |
| `CLR-STRUCT-05` | 缩略图、封面、图标和颜色只能辅助，不能作为记录身份、状态、权限、错误或可操作性的唯一表达。 |

## 交互区域与点击模型

整张卡片不得包成一个大链接再在内部塞按钮、菜单、checkbox 或复制控件。打开详情区、选择区和操作区必须是独立交互区域。

| 规则 ID | 规则 |
| --- | --- |
| `CLR-ZONE-01` | 卡片可有一个明确的主打开详情区，但该区域不得包裹内部按钮、菜单、checkbox、复制控件、链接或可展开控件。 |
| `CLR-ZONE-02` | 选择区必须有独立 checkbox 或等价选择控件，名称包含记录身份和选择状态；点击选择不得同时打开详情。 |
| `CLR-ZONE-03` | 操作区必须使用真实按钮或菜单触发器；更多菜单、危险操作和批量操作不得依赖整卡右键、hover 或长按。 |
| `CLR-ZONE-04` | 复制、打开外链、下载、预览、编辑和危险操作必须有各自动作对象，不能共用一个无语义卡片点击 handler。 |
| `CLR-ZONE-05` | 拖拽、滑动、长按或精确指针不能成为关键操作唯一路径；必须提供点击和键盘替代。 |

## 选择、批量与操作

选择状态必须读取稳定记录 ID，不得用当前数组索引或 DOM 顺序。

| 规则 ID | 规则 |
| --- | --- |
| `CLR-SEL-01` | 只有 `selection-action` 档位可创建 `selectionBinding`；其他档位选择 DOM、state、handler 和 request 均为 0。 |
| `CLR-SEL-02` | 卡片选择、全选、全部筛选结果、排除项、不可选原因、批量确认和部分成功必须与来源结果快照、权限范围和数据版本绑定。 |
| `CLR-SEL-03` | 选择卡片不得打开详情、切换预览、触发菜单或提交单卡片操作。 |
| `CLR-ACT-01` | 单卡片操作读取当前 `cardIdentityMap`、权限版本和结果快照；迟到操作结果不得写回新卡片或旧权限。 |
| `CLR-ACT-02` | 危险操作必须转交 `risk-actions.md`；编辑入口必须转交 `record-editing-surfaces.md`；详情预览必须转交 `preview-pane.md`。 |

## 编辑禁止

卡片内不得承载新增、编辑、复制创建、单元格编辑、字段保存、行内保存或完整字段表单。

| 规则 ID | 规则 |
| --- | --- |
| `CLR-EDIT-01` | 卡片内不得渲染 input、textarea、select、combobox、日期选择器、开关式字段编辑、排序输入、标签编辑、单元格编辑、字段保存按钮或行内保存按钮。 |
| `CLR-EDIT-02` | 卡片列表顶部、底部、卡片内部、批量工具栏或空态不得内嵌新增/编辑表单；只能提供进入 Dialog、Drawer 或独立页的入口。 |
| `CLR-EDIT-03` | “快速修改状态”“编辑标签”“调整排序”等小动作也不得在卡片内部直接改字段；必须进入记录编辑承载面或命令式风险操作流程。 |

## 请求、刷新与迟到响应

| 规则 ID | 规则 |
| --- | --- |
| `CLR-REQ-01` | 查询、排序、分页、刷新、自动刷新和权限变化必须建立不可变结果快照和请求代次。 |
| `CLR-REQ-02` | 迟到响应不得写回新卡片、新权限或已卸载列表；只有 owner、请求代次、结果快照、权限版本、租户/工作区和资源版本均匹配时才可提交。 |
| `CLR-REQ-03` | 刷新已有结果时保留旧卡片并标记 stale/refreshing；不得闪成空白或用旧结果伪装新结果。 |
| `CLR-REQ-04` | 加载、空态、无结果、刷新失败、部分结果、未知结果和无权限状态必须由 `feedbackBinding` 承载，Toast 不能作为唯一反馈。 |

## 权限与无泄露

无权限或权限降级不得泄露旧标题、旧封面、旧缩略图、旧标签、旧状态、旧数量、旧文件名、旧菜单项、旧错误或旧 ARIA label。

| 规则 ID | 规则 |
| --- | --- |
| `CLR-PERM-01` | 权限待解析时显示安全骨架或泛化说明，不得短暂闪现旧卡片身份、封面、状态、菜单或数量。 |
| `CLR-PERM-02` | 隐藏、禁用、只读、未启用和无权限必须可区分；原因安全可展示时必须有文本或可访问描述。 |
| `CLR-PERM-03` | 权限降级、租户/工作区切换、角色变化、能力关闭、记录删除和来源范围变化后，旧卡片 DOM、state、handler、request、菜单、复制内容和 ARIA 引用必须失效。 |

## 响应式、键盘与可访问性

重要字段、权限原因、错误状态、恢复入口和主要操作不得只靠 hover、右键、隐藏菜单、图标、颜色、封面图或截断文本表达。

移动端、200% 缩放、低高度、长标题、翻译扩展和字体放大不得删除记录身份、主状态、错误/权限说明、选择摘要、主要操作、分页/刷新和恢复入口。

| 规则 ID | 规则 |
| --- | --- |
| `CLR-RSP-01` | 列数、最小卡片宽度、间距、截断、展开、分页和底部工具栏必须由 `responsivePolicy` 声明，不得按设备名称临时猜测。 |
| `CLR-RSP-02` | 移动端卡片可以单列、分组或进入 Drawer/独立页查看详情，但不能删除核心字段、权限说明、错误恢复、选择摘要、分页、刷新和主要操作。 |
| `CLR-RSP-03` | 200% 缩放、系统字体放大、翻译扩展和长单词下，卡片自然增高；不得固定高度裁掉状态、字段 label、按钮或错误说明。 |
| `CLR-A11Y-01` | 卡片列表、每张卡片、选择控件、操作区、菜单、分页和状态消息必须有可区分可访问名称。 |
| `CLR-A11Y-02` | Tab 顺序只进入真实交互控件；静态字段不额外制造 tabindex。 |
| `CLR-A11Y-03` | 断点转换、排序、刷新、权限变化和卡片移除导致焦点目标消失时，只移动一次到同记录等价控件、结果摘要或安全说明。 |

## 生命周期与 disposal

| 规则 ID | 规则 |
| --- | --- |
| `CLR-LIFE-01` | 路由离开、owner 卸载、权限收敛、结果范围失效或视图切换时，卡片列表实例必须进入幂等 disposal 或受控迁移。 |
| `CLR-LIFE-02` | disposal 失效查询、刷新、自动刷新、菜单、复制回执、预览入口、选择协调、操作结果、焦点任务和公告回调。 |
| `CLR-LIFE-03` | 旧实例迟到回调不得清理新实例、表格实例、预览面板、编辑承载面或其他卡片列表。 |
| `CLR-LIFE-04` | 未实际执行浏览器、键盘、读屏、触摸、断点、真实数据竞态和权限切换检查时，必须标为未验证。 |

## 可执行验收检查

1. **状态模型**：记录 `cardListResultState` 全字段，断言 owner、结果快照、权限、字段映射和交互区域独立存在。
2. **能力档位**：分别构造 `display`、`item-action`、`selection-action`；断言能力只按档位渲染，关闭能力 DOM/state/handler/request 为 0。
3. **卡片结构**：检查每张卡片有记录级名称、字段 label/value、状态文本、空值/脱敏策略和安全缩略图；卡片列表不是营销卡片墙。
4. **点击区域**：断言整张卡片没有包成一个大链接再包内部按钮、菜单、checkbox 或复制控件；打开详情区、选择区和操作区必须是独立交互区域。
5. **选择与操作**：选择状态使用稳定记录 ID；选择不会打开详情或菜单；单卡片操作、危险操作、预览和编辑入口转交对应 owner。
6. **编辑禁止**：卡片内 input、textarea、select、combobox、日期选择器、字段保存、行内保存和完整字段表单数量为 0。
7. **请求与迟到响应**：快速刷新、排序、翻页、权限变化、记录删除和 owner 卸载后，迟到响应不得写回新卡片、新权限或已卸载列表。
8. **权限无泄露**：无权限或权限降级时，旧标题、旧封面、旧缩略图、旧标签、旧状态、旧数量、旧文件名、旧菜单项、旧错误和旧 ARIA label 均不暴露。
9. **响应式与可访问性**：移动端、200% 缩放、低高度、长标题、翻译扩展和字体放大下，记录身份、主状态、错误/权限说明、选择摘要、主要操作、分页/刷新和恢复入口仍可达。
10. **运行时报告边界**：真实浏览器、键盘、读屏、触摸、断点、权限切换、真实数据竞态和真实组件运行时未执行时，最终报告必须逐项标为未验证。

## 完成前检查

- 是否声明 `cardListResultState` 及全部必要字段。
- 是否证明卡片列表不是营销卡片墙，并有记录身份、字段映射、状态文本和可访问名称。
- 是否禁止整张卡片包大链接后嵌套按钮、菜单、checkbox 或复制控件。
- 是否声明 `capabilityTier`，并让 display、item-action、selection-action 能力边界互不串线。
- 是否使用稳定记录 ID 做选择和操作绑定，而不是数组索引或 DOM 顺序。
- 是否确认卡片内不存在新增、编辑、复制创建、字段保存、行内保存或完整字段表单。
- 是否保证重要字段、权限原因、错误状态、恢复入口和主要操作不只靠 hover、右键、隐藏菜单、图标、颜色、封面图或截断文本表达。
- 是否保证移动端、200% 缩放、低高度和长文本下核心信息与操作仍可达。
- 是否实现迟到响应和权限无泄露边界。
- 未实际执行运行时检查时，是否明确标为未验证，并列出所需验证。
