# 异步任务与任务中心交互规范

适用于 async job、background task、job center、task center、异步任务、后台任务、任务中心、任务详情、任务进度、导入任务、导出任务、批量任务、报表生成、AI 生成、同步任务、取消任务、重跑任务、任务重试、结果领取、错误明细、未知结果和过期任务。本文件是异步任务生命周期、任务中心恢复、跨页面任务状态、任务产物领取、取消/重试语义、权限安全、可访问性和验收的唯一事实来源。

文件选择、上传队列、导入预检、字段映射和文件级错误继续执行 [上传与导入交互规范](uploads-imports.md)。危险操作确认、风险分级、撤销窗口、取消任务和重跑任务的风险确认继续执行 [危险操作与恢复交互规范](risk-actions.md)。Toast、Notification、Alert、Banner 和消息去重继续执行 [全局反馈与通知交互规范](global-feedback.md)。表格选择和批量范围继续执行 [数据表格交互规范](data-tables.md)。管理台跨页面权限、审计和治理继续执行 [管理台完整治理交互规范](admin-console.md)。

## 范围与边界

本 owner 覆盖：

- 导入任务、导出任务、批量任务、报表生成、AI 生成、同步任务、Webhook 回放、计划任务手动运行、任务取消、任务重跑、任务重试和结果领取。
- 任务创建、排队、运行、等待外部系统、取消中、已取消、成功、部分成功、失败、未知结果、过期、无权限查看和产物失效。
- 任务中心列表、任务详情、来源页面持久状态、跨页面 Notification、结果页、下载入口、错误明细入口和恢复路径之间的 owner 分工。
- 任务身份、幂等、输入快照、权限版本、租户/工作区、进度、产物、审计、迟到回调、轮询/订阅、焦点恢复和移动端承载。

本 owner 不覆盖：

- 后端队列、worker 调度、数据库事务、文件存储、模型生成算法、外部系统协议或通知服务实现。
- 文件上传和导入预检的文件级生命周期。
- 风险动作确认文案、撤销窗口和输入确认。
- Toast/Notification 视觉样式和消息系统完整实现。

## `asyncJobState`

每个异步任务入口、任务中心条目或任务详情必须维护 `asyncJobState`：

| 字段 | 语义 |
| --- | --- |
| `jobOwnerId` | 当前任务 owner 稳定身份。 |
| `jobId` | 服务端任务身份；服务端任务创建前使用候选身份，并在创建结果返回后绑定。 |
| `jobKind` | `import`、`export`、`bulk-action`、`report-generation`、`ai-generation`、`sync`、`webhook`、`scheduled-run`、`risk-action`。 |
| `sourceSurface` | 任务来源页面、Dialog、Drawer、列表、详情、任务中心、结果页或外部回调入口。 |
| `requestIdentity` | 操作 ID、幂等键、权限版本、租户/工作区、输入快照、目标快照和发起者。 |
| `inputSnapshot` | 文件、筛选、选择、配置、提示词、时间范围、导出范围、同步范围或外部系统目标快照。 |
| `jobPhase` | `draft`、`creating`、`queued`、`running`、`waiting`、`cancel-requested`、`cancelled`、`succeeded`、`partial-succeeded`、`failed`、`unknown`、`expired`。 |
| `progressState` | 百分比、阶段、已处理数量、总数、未知进度、数据延迟、最近更新时间和进度来源。 |
| `resultState` | 成功、部分成功、失败、取消、未知、过期、无权限查看、结果可领取和结果已领取状态。 |
| `cancelPolicy` | 是否可取消、取消请求语义、取消中展示、服务端回执要求和取消失败恢复。 |
| `retryPolicy` | 重试范围、幂等语义、是否会重复执行、成功项处理、失败项处理和权限复核。 |
| `artifactState` | 导出文件、错误明细、结果文件、报告、生成内容或外部同步回执的可见性、下载身份、有效期和权限。 |
| `notificationBinding` | Toast、Notification、任务中心、来源页面和结果页的 primary owner、去重键和关闭语义。 |
| `auditBinding` | 审计可用性、审计请求身份、写入结果、查看位置和审计失败说明。 |
| `permissionBoundary` | 创建、查看、取消、重试、下载、领取结果、查看错误明细和查看审计的权限版本。 |
| `responsivePolicy` | 移动端任务入口、任务详情、底部操作、返回路径、恢复路径和安全区域策略。 |

任务状态不能只绑定到按钮 loading、Toast 文案、Notification 标题、表格行文案、局部 `loading` 布尔值或任务中心的一行文本。任何会跨页面、长耗时、可取消、可重试、可领取结果或可能未知的任务，都必须有持久 owner。

## 任务创建、身份和幂等

任务创建必须在请求发送前冻结 `requestIdentity` 和 `inputSnapshot`。点击、Enter、Space、触摸、双击、网络重试、自动重试和事件重放不能创建多个等价任务；要么复用同一幂等语义，要么拒绝重复意图并说明已有任务。

任务创建成功前只能展示 `creating`、创建失败或创建结果未知；不得提前写成 queued、running 或 succeeded。创建失败必须保留来源上下文、输入快照、权限版本、错误说明和恢复动作；不能默认清空表单、关闭承载面或丢弃候选任务。

同一任务从来源页面进入任务中心、从 Notification 进入任务详情、从结果页返回来源列表时，必须复用同一 `jobId`、`requestIdentity`、`permissionBoundary` 和审计绑定。不同任务不得共用一个笼统的 loading、progress 或 Toast key。

## 排队、运行、进度和刷新

`jobPhase` 必须互斥，至少区分 draft、creating、queued、running、waiting、cancel-requested、cancelled、succeeded、partial-succeeded、failed、unknown 和 expired。不得把 queued、running、waiting、cancel-requested 和 unknown 合并成“处理中”；不得把 partial-succeeded 和 succeeded 合并成“完成”。

进度可用时展示真实进度和最近更新时间；进度不可用时展示未知进度、排队中、运行中或等待外部系统，不得伪造百分比。已处理数量、总数、阶段名称、数据延迟和更新时间来自服务端、订阅或可信快照；无法证明时必须标为未知。

轮询、订阅、后台刷新和迟到回调必须匹配 `jobOwnerId`、`jobId`、租户/工作区、权限版本和任务代次。不匹配时只丢弃或转入对应持久 owner，不得覆盖当前页面的新任务状态。

## 关闭、离开、取消和未知结果

关闭 Dialog、Drawer、Toast、Notification、来源页面、浏览器 Tab 或移动端系统返回，只能表达客户端关闭或停止等待，不得伪装成服务端任务已取消。

取消请求已发送不等于任务已取消。必须区分不可取消、可请求取消、取消请求已发送、取消中、服务端已取消、取消失败、已完成无法取消和未知结果。

未知结果不得伪装成成功或失败。网络中断、页面卸载、轮询超时、后端未返回终态、外部系统无回执、任务中心查询失败和取消结果不明时，必须提供检查最新状态、进入任务中心、刷新任务详情、查看审计或联系支持路径。

取消任务和重跑任务若会影响数据、导出、权限、外部系统或关联对象，必须先执行 `risk-actions.md` 的风险确认；确认完成前请求数为 0。取消中不得隐藏任务，不能把按钮 disabled 当作唯一说明。

## 任务中心、通知和来源页面

跨页面、长耗时、可取消、可重试、可领取结果或可能未知的任务，必须有任务中心、任务详情页、来源页面持久区域或等价持久 owner。Toast 和 Notification 只能辅助提醒，不能作为唯一状态、唯一错误、唯一下载入口或唯一恢复路径。

任务中心列表必须展示或可达地说明任务类型、来源、状态、进度、发起者、创建时间、更新时间、结果有效期、权限状态和可执行动作。任务详情必须展示输入快照摘要、当前状态、结果、错误明细、审计位置、权限说明和恢复动作。

来源页面可以展示轻量任务条、结果摘要或最近任务入口，但不能创建与任务中心不一致的第二套真相。Notification 点击必须进入任务详情、结果页、来源页面持久区域或安全降级说明；关闭 Notification 不得取消任务、删除结果、删除审计或放弃下载入口。

## 结果、产物和部分成功

导出文件、错误明细、结果文件、AI 生成内容、报表文件和同步回执都属于 `artifactState`。领取、下载、复制、重试和分享前必须复核任务身份、权限版本、租户/工作区、有效期和请求身份。旧链接、旧通知、旧缓存和浏览器历史入口不得绕过权限复核。

部分成功必须说明成功、失败、跳过、冲突和未知的对象范围，并提供错误明细、重试失败项、下载结果、查看任务详情或进入来源页面的路径。不得只用 Toast 表示部分成功，不得只显示总数而不给用户能理解的影响范围。

产物过期、结果已领取、权限变化、租户切换、任务删除、任务归档或外部系统回执失效后，旧下载、复制、分享、错误明细和重试入口必须失效或重新证明安全。

## 权限、安全和审计

权限是任务生命周期的安全边界。创建、查看、取消、重试、领取结果、下载产物、查看错误明细和查看审计都可能需要不同权限；不能因为用户曾经创建任务就永久允许查看或下载结果。

权限降低、租户/工作区切换、角色变化、任务来源对象删除、筛选范围失效或任务过期后，旧任务标题、对象名称、数量、文件名、错误明细、下载链接、结果摘要、Notification 和任务中心动作必须重新证明安全；无法证明时隐藏、失效或替换为安全说明。无权限状态不得泄露敏感对象名称、数量、字段、文件名、错误明细、内部 ID、导出范围、提示词或旧缓存。

`auditBinding` 必须说明任务创建、取消、重试、完成、失败、下载、领取结果和权限拒绝是否有审计记录、审计写入结果、查看位置和审计不可用时的恢复路径。审计失败不等于任务失败，但必须说明业务结果是否已生效。

## 可访问性、焦点和移动端

任务类型、状态、进度、取消中、失败、部分成功、未知、过期、权限拒绝、结果可领取和恢复动作必须有可见文本或可访问公告；不能只靠颜色、动画、spinner、进度条、图标、Tooltip、Toast 或 Notification。

任务列表和任务详情必须支持键盘访问。取消、重试、重跑、下载、领取结果、下载错误明细、查看审计和返回来源页面的按钮必须有动作对象和可访问名称。状态更新公告必须去重；同一任务结果不能被来源页面、Toast、Notification、任务中心和 live region 重复播报。

移动端不得删除任务中心入口、任务状态、进度、取消中、重试、结果领取、错误明细、未知结果说明、权限说明或恢复路径。低频字段可以折叠，但必须可发现、可触达、可键盘或辅助技术访问，并保持与 PC 相同的业务结果。

低高度、虚拟键盘、动态 viewport、四向 safe area、系统字体放大、200% 缩放、触摸、系统返回、WebView 返回和浏览器 Back 下，任务状态、主要恢复动作、取消中说明、错误明细和结果领取路径必须可达；底部操作和 Toast/Snackbar 不得遮挡任务恢复入口。

## 生命周期和清理

每个任务 owner 必须登记创建请求、取消请求、重试请求、轮询、订阅、定时器、下载预签名刷新、焦点恢复、公告和缓存订阅。关闭承载面、路由变化、owner 卸载、权限变化、租户切换或任务集合替换时，进入 disposal：取消或失效客户端任务、回调、轮询、订阅、定时器和公告；不得取消仍在服务端执行的任务，除非用户明确触发并完成服务端取消流程。

迟到成功、失败、部分成功、取消、未知或权限拒绝结果必须匹配当前 live owner；不匹配时丢弃或写入对应任务中心持久 owner。焦点恢复只能发生一次；来源目标已移除、无权限或不可见时，恢复到明确后备目标。

## 完成前检查

- 验证每个异步任务入口、任务中心条目或任务详情声明 `asyncJobState`、`jobOwnerId`、`jobId`、`jobKind`、`sourceSurface`、`requestIdentity`、`inputSnapshot`、`jobPhase`、`progressState`、`resultState`、`cancelPolicy`、`retryPolicy`、`artifactState`、`notificationBinding`、`auditBinding`、`permissionBoundary` 和 `responsivePolicy`。
- 验证任务创建前冻结 `requestIdentity` 和 `inputSnapshot`；重复点击、Enter、Space、触摸、网络重试和事件重放不会创建多个等价任务。
- 验证关闭 Dialog、Drawer、Toast、Notification、来源页面、浏览器 Tab 或移动端系统返回，只能表达客户端关闭或停止等待，不得伪装成服务端任务已取消。
- 验证取消请求已发送不等于任务已取消；取消中、服务端已取消、取消失败、已完成无法取消和未知结果可区分。
- 验证未知结果不得伪装成成功或失败，并提供检查最新状态、进入任务中心、刷新任务详情、查看审计或联系支持路径。
- 验证 Toast 和 Notification 只能辅助提醒，不能作为唯一状态、唯一错误、唯一下载入口或唯一恢复路径。
- 验证领取、下载、复制、重试和分享前必须复核任务身份、权限版本、租户/工作区、有效期和请求身份。
- 验证部分成功说明成功、失败、跳过、冲突和未知的对象范围，并提供错误明细、重试失败项、下载结果或任务详情路径。
- 验证无权限状态不得泄露敏感对象名称、数量、字段、文件名、错误明细、内部 ID、导出范围、提示词或旧缓存。
- 验证移动端不得删除任务中心入口、任务状态、进度、取消中、重试、结果领取、错误明细、未知结果说明、权限说明或恢复路径。
- 验证路由变化、owner 卸载、权限变化、租户切换和任务集合替换后的 disposal：客户端请求、回调、轮询、订阅、定时器和公告全部取消或失效，但不会伪装成服务端任务取消。
- 真实浏览器、触摸、键盘、屏幕阅读器、权限变化、轮询/订阅、下载、任务中心和移动端视口未实际执行时，必须明确标为未验证，并列出所需验证。
