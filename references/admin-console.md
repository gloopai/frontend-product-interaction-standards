# 管理台完整治理交互规范

## 范围

适用于后台、管理台、控制台、运营后台、SaaS console 和内部工具的跨页面产品治理。本文件是管理台页面级场景、权限、风险、审计、任务、报表和全局反馈的唯一事实来源。

## 与组件 owner 的关系

App Shell、应用外框、管理台外框、全局导航、侧边导航、顶部导航、用户菜单、工作区/租户切换、全局搜索入口、通知入口和移动端导航 Drawer 必须同时执行 `references/app-shell-navigation.md`；本文件负责管理台跨页面治理，`app-shell-navigation.md` 负责持久外框 owner、全局入口转交、当前项绑定和移动端外框形态。

表格、报表、列表、分页、筛选、排序、选择和批量操作读取 `data-tables.md`；表单、设置页、编辑页和提交失败恢复读取 `forms.md`；确认、详情、编辑或结果弹窗读取 `dialogs.md` / `drawers.md`；选择器读取 `selects-comboboxes.md`；跨端布局、导航折叠和安全区域读取 `responsive-adaptive.md`。当 `admin-console` 与组件 owner 都适用时，两者都执行；冲突时停止并请用户裁决。

管理台规范是跨页面 owner，不重新定义上述组件的局部交互、数据表格、表单、Dialog、Drawer、Select 或响应式细节；它定义页面能力边界、跨页面状态和安全收敛要求。

概览页、仪表盘首页、管理台首页、运营看板、业务看板、指标总览、报表总览和 dashboard landing 必须同时执行 `references/overview-dashboard-pages.md`；本文件继续负责管理台跨页面治理，`overview-dashboard-pages.md` 负责页面级共享快照、模块一致性、告警优先级、移动端总览和局部 owner 转交。

审批、审核、提交审批、通过、驳回、撤回、转交、加签、委托、催办、待办审批和批量审批必须同时执行 `references/approval-workflows.md`；本文件继续负责管理台跨页面治理，`approval-workflows.md` 负责审批实例、节点、审批人、意见/附件、通知、审计和工作流决策快照。

## 场景与状态模型

每个页面声明一个或多个 `consoleSurface`：`overview-dashboard`、`report`、`record-list`、`record-detail`、`record-editor`、`settings`、`job-center`、`audit-log`。页面级状态至少包含 `navigationState`、`permissionState`、`surfaceState`、`riskState`、`auditState`、`taskState`、`feedbackState`；组件 owner 的局部状态不得替代这些页面级 owner。

`navigationState` 记录当前导航、返回路径和离开保护；`permissionState` 记录租户、工作区、角色、权限版本和已解析能力；`surfaceState` 记录加载、内容、空态、错误与延迟；`riskState` 记录风险声明、确认和结果回执；`auditState` 记录审计可用性与写入回执；`taskState` 记录导入、导出和异步任务的服务端状态；`feedbackState` 记录页面内反馈与跨页面通知的 primary owner。

页面实现必须把产品显式声明的能力写入能力清单。列表是否支持选择、行操作、批量、导出或跳转必须由产品显式声明；报表和仪表盘默认只读展示，不能从存在表格或图表自动推导这些能力。

## AC-IA 信息架构

| 规则 ID | 规则 |
| --- | --- |
| AC-IA-01 | 页面标题、主内容和当前导航项必须稳定可定位。 |
| AC-IA-02 | 面包屑和返回路径必须声明，返回恢复必须重校验权限、版本和范围。 |
| AC-IA-03 | Tabs 只用于同一资源或任务上下文，不隐藏互不相关页面。 |
| AC-IA-04 | Dirty 表单、未完成导入、危险确认和不可安全中断任务在离开前必须确认或安全中止。 |

对应验收：AC-A1、AC-A2。

## AC-PERM 权限和租户

权限是安全边界，不是视觉开关。权限、租户、工作区、角色或权限版本改变时，任何不能重新证明安全的数据、字段、菜单、选择、确认、任务入口和下载都不得继续暴露。

| 规则 ID | 规则 |
| --- | --- |
| AC-PERM-01 | 权限/租户/工作区/角色/权限版本变化后原子计算 `resolvedSurface`、可见范围、可执行操作和可导出范围。 |
| AC-PERM-02 | 无法同步证明仍可见的数据、字段、操作和导出入口先隐藏或替换安全占位。 |
| AC-PERM-03 | 权限不足状态解释原因和恢复路径，但不得泄露敏感对象名称、数量或字段。 |
| AC-PERM-04 | 权限降级清理选择、菜单、确认、操作快照、导入导出入口和敏感下载，焦点只迁移一次。 |

对应验收：AC-A3、AC-A4。

## AC-RISK 风险操作

| 规则 ID | 规则 |
| --- | --- |
| AC-RISK-01 | 风险操作必须声明 `riskLevel`、`impactScope`、`confirmationPolicy`、`requestIdentity`、`resultReceipt`；`requestIdentity` 至少包含操作 ID、幂等键、权限版本、目标快照和发起者，`resultReceipt` 至少区分成功、部分成功、失败、冲突、未知结果和审计回执。 |
| AC-RISK-02 | 删除、停用、权限变更、批量修改、敏感导出、重跑、取消、清空和不可逆配置变更默认是风险操作。 |
| AC-RISK-03 | 风险操作结果不能只靠 Toast，必须有页面内回执或可恢复状态。 |
| AC-RISK-04 | 未知结果不得伪装成成功或失败，必须提供检查最新状态或进入任务中心路径。 |

关闭确认、Escape、浏览器返回或离开页面只关闭客户端确认，不得把已发送请求写成“已取消”；取消请求也必须等待服务端结果。

对应验收：AC-A5、AC-A6。

## AC-AUDIT 审计

| 规则 ID | 规则 |
| --- | --- |
| AC-AUDIT-01 | 变更操作必须能追踪主体、时间、租户/工作区、目标、请求身份和结果。 |
| AC-AUDIT-02 | 页面必须说明审计可用性、回执位置和审计失败恢复。 |
| AC-AUDIT-03 | 审计日志区分无数据、无权限、筛选无结果、审计服务不可用和数据延迟。 |
| AC-AUDIT-04 | 审计查询和导出不得泄露无权访问主体、对象或租户名称。 |

对应验收：AC-A7。

## AC-JOB 导入、导出和任务

### 统一任务绑定契约

每一个导入、导出和异步任务必须声明并持续保留同一份完整绑定契约：快照、权限、幂等、进度、结果、失败恢复。导入、导出和异步任务均继承此完整契约；任一类别不可因同步、异步、页面关闭、重试、下载或跨页面通知而省略。快照覆盖输入、范围、筛选、映射或配置；权限覆盖创建、执行、查看结果和下载时的复核；幂等覆盖提交与重试身份；进度覆盖可观察的排队与执行进展；结果覆盖成功、部分成功、失败、取消、未知结果或过期；失败恢复覆盖错误详情、可恢复下一步和不重复执行的说明。

| 规则 ID | 规则 |
| --- | --- |
| AC-JOB-01 | 导入声明文件类型、大小、字段映射、预检查、提交快照、幂等键、部分成功、错误文件和重试。 |
| AC-JOB-02 | 预检查失败不得创建执行任务；执行失败保留错误文件、行号和下一步。 |
| AC-JOB-03 | 导出声明范围、筛选快照、权限范围、敏感字段、生成方式、过期时间和下载身份。 |
| AC-JOB-04 | 下载链接绑定权限和请求身份，过期或权限变化后失效。 |
| AC-JOB-05 | 异步任务区分排队、运行中、成功、部分成功、失败、取消中、已取消、未知结果和过期。 |
| AC-JOB-06 | 关闭页面不能伪装成取消任务，取消请求不能伪装成服务端已停止。 |

导出与导入的快照必须可由任务或页面内回执追溯；重试必须说明幂等键、已成功行的处理方式和是否会重复执行。下载链接过期、权限变化或请求身份不匹配时必须拒绝下载，不以旧通知或缓存入口绕过复核。

对应验收：AC-A8、AC-A9。

## AC-REPORT 报表与仪表盘

| 规则 ID | 规则 |
| --- | --- |
| AC-REPORT-01 | 报表和仪表盘默认只读展示，不自动推导选择、行操作或批量。 |
| AC-REPORT-02 | 指标声明口径、时间范围、刷新时间、数据延迟、权限范围和过滤条件。 |
| AC-REPORT-03 | 报表空态区分当前权限无数据、筛选无结果、指标尚未产生、服务失败、数据延迟和口径不可用。 |
| AC-REPORT-04 | 图表、指标卡和明细共享同一筛选/权限快照；不同范围必须说明。 |
| AC-REPORT-05 | 钻取、导出和订阅是可选能力，启用时执行相关 owner，关闭时入口为 0。 |

对应验收：AC-A10。

## AC-FB 全局反馈

| 规则 ID | 规则 |
| --- | --- |
| AC-FB-01 | Toast 只能辅助反馈，不能是唯一错误、成功回执、审计凭证或恢复入口。 |
| AC-FB-02 | Alert 用于页面内持续状态、阻断问题和重要恢复；Notification 用于跨页面异步任务和系统消息。 |
| AC-FB-03 | Popover / Tooltip 不能承载唯一必读权限原因、错误、确认后果或操作入口。 |
| AC-FB-04 | 同一完整消息只有一个 primary owner，不重复播报。 |

对应验收：AC-A11。

## 响应式与报告契约

| 规则 ID | 规则 |
| --- | --- |
| AC-RSP-01 | 移动端可折叠低频导航、筛选、列和次要操作，但核心任务、权限、错误恢复、审计回执和危险确认不能消失。 |
| AC-RSP-02 | 后台页面优先扫描、比较和重复操作，不使用营销式 hero 或装饰性大卡片承载主要工作区。 |
| AC-REPORTING-01 | 应用报告必须声明 `consoleSurface`、权限/租户、页面级状态 owner、风险操作、导入导出、审计、报表能力和未验证边界。 |
| AC-REPORTING-02 | 不适用能力必须给出 DOM、state、handler/event、request 四类零值证据。 |

未执行浏览器、屏幕阅读器、触摸设备或真实组件运行时验证时，报告必须明确标为“未验证”，不得把设计推断描述为运行时事实。

## 验收场景

每个验收均须记录初始状态、事件序列、预期状态、DOM/ARIA、事件日志；未实际运行的 DOM/ARIA、事件日志或设备验证标为未验证。

### AC-A1：稳定导航定位

- 初始状态：已声明 `navigationState`、标题、主内容和当前导航项。
- 事件序列：进入页面、切换同一资源上下文的 Tab、返回。
- 预期状态：标题、主内容和当前导航项始终稳定可定位；Tabs 不代替无关页面导航。
- DOM/ARIA：标题、主内容地标、当前导航语义及 Tab 语义存在；运行时未验证则标注未验证。
- 事件日志：记录进入、导航与返回路径解析。

### AC-A2：离开与返回保护

- 初始状态：Dirty 表单、未完成导入、危险确认或不可安全中断任务之一存在。
- 事件序列：点击返回、面包屑、浏览器后退或导航到其他页面。
- 预期状态：先确认或安全中止；恢复时重校验权限、版本和范围。
- DOM/ARIA：离开确认符合相应 Dialog owner；运行时未验证则标注未验证。
- 事件日志：记录离开意图、确认/中止和恢复后的权限重校验。

### AC-A3：权限与租户原子收敛

- 初始状态：页面展示已授权的记录、菜单、选择、确认或下载入口。
- 事件序列：变更租户、工作区、角色或权限版本。
- 预期状态：原子重算 `resolvedSurface`、可见/操作/导出范围；无法证明安全的旧内容先隐藏或安全占位。
- DOM/ARIA：被撤销能力不保留可操作 DOM 或可访问名称；运行时未验证则标注未验证。
- 事件日志：记录权限快照版本、收敛开始、清理与新范围生效。

### AC-A4：权限不足不泄露

- 初始状态：用户不具备对象、字段或操作权限。
- 事件序列：进入受限页面或在权限降级后尝试操作。
- 预期状态：说明恢复路径而不泄露敏感对象名称、数量、字段、旧菜单或旧下载；焦点仅迁移一次。
- DOM/ARIA：安全占位可读，敏感按钮、链接及其可访问名称不存在；运行时未验证则标注未验证。
- 事件日志：记录拒绝类别及恢复路径，不记录无权对象内容。

### AC-A5：风险操作页面内回执

- 初始状态：已声明风险操作的风险级别、影响范围、确认策略；`requestIdentity` 具有 `{operationId, idempotencyKey, permissionVersion, targetSnapshot, initiator}`，`resultReceipt` 具有 `{success, partial-success, failure, conflict, unknown, auditReceipt}` 六类状态。
- 事件序列：确认删除、停用、权限变更、批量修改或敏感导出。
- 预期状态：请求发送前冻结上述五个请求身份字段，重放只能使用同一幂等语义；权限版本或目标快照过期进入冲突/重确认，不得继续执行。结果必须落入成功、部分成功、失败、冲突或未知结果之一，并独立记录审计回执可用性；页面内回执或可恢复状态可定位审计或任务，Toast 仅可辅助提示。
- DOM/ARIA：确认与回执符合对应组件 owner；运行时未验证则标注未验证。
- 事件日志：逐次记录确认、五字段请求身份、提交、五类互斥结果、审计回执和回执位置；断言幂等重放请求数不增加、旧权限版本/旧目标快照的执行写入为 0。

### AC-A6：未知与取消边界

- 初始状态：风险请求尚未发送、已发送或等待结果。
- 事件序列：关闭确认、Escape、离开页面、发送取消请求或网络中断。
- 预期状态：未发送请求可关闭；已发送或未知结果不伪装为取消/成功/失败，提供刷新状态或任务中心路径；取消中等待服务端回执。
- DOM/ARIA：未知和取消中为持续页面状态；运行时未验证则标注未验证。
- 事件日志：记录客户端关闭、取消请求、服务端回执及最终状态，彼此不混淆。

### AC-A7：审计可用性与空态

- 初始状态：进入 `audit-log`，可用性未知或已解析。
- 事件序列：查询正常日志、无权限、无数据、筛选无结果、服务不可用或数据延迟。
- 预期状态：五种状态分别呈现；变更可追踪主体、时间、租户/工作区、目标、请求身份和结果；导出不泄露无权信息。
- DOM/ARIA：状态说明和恢复入口在页面内可访问；运行时未验证则标注未验证。
- 事件日志：记录查询条件、可用性、延迟、失败恢复和审计写入结果。

### AC-A8：导入预检查与恢复

- 初始状态：导入继承统一任务绑定契约，声明快照、权限、幂等、进度、结果、失败恢复，以及文件类型、大小、映射和提交快照。
- 事件序列：上传、映射、预检查失败、预检查通过、执行失败、部分成功或重试。
- 预期状态：预检查失败不创建执行任务；失败保留错误文件、行号和下一步；重试说明幂等与成功行处理。
- DOM/ARIA：错误摘要、错误文件与恢复路径在页面内可达；运行时未验证则标注未验证。
- 事件日志：验证并记录导入的完整契约：文件/映射快照、创建/执行/查看权限、幂等键、排队与执行进度、最终结果、错误文件/行号及失败恢复动作。

### AC-A9：导出与异步任务鉴权

- 初始状态：导出和异步任务均继承统一任务绑定契约，分别声明快照、权限、幂等、进度、结果、失败恢复；导出另声明范围、筛选快照、权限范围、敏感字段、过期时间和下载身份。
- 事件序列：创建导出、任务排队/运行、下载、权限变化、链接过期、关闭页面或取消。
- 预期状态：下载链接绑定权限和请求身份，权限变化或过期后失效；任务状态完整区分；关闭页面不等于取消，取消请求不等于已停止。
- DOM/ARIA：任务状态、进度、失败恢复和失效说明可访问；运行时未验证则标注未验证。
- 事件日志：验证并记录导出和异步任务的完整契约：导出/输入快照、创建/执行/查看/下载权限复核、幂等键、排队与执行进度、最终结果、链接拒绝、错误详情、失败恢复、取消请求与服务端最终状态。

### AC-A10：只读报表与数据口径

- 初始状态：`consoleSurface` 为 `overview-dashboard` 或 `report`，未声明选择、行操作、批量、钻取、导出或订阅。
- 事件序列：进入、筛选、刷新、数据延迟、空态或权限变化。
- 预期状态：默认只读，未声明能力的入口为 0；指标展示口径、时间范围、刷新时间、延迟、权限范围与过滤条件；图表、指标卡和明细共享同一快照。
- DOM/ARIA：图表与指标说明、各空态和可选能力入口符合声明；运行时未验证则标注未验证。
- 事件日志：记录筛选/权限快照、刷新、延迟和口径可用性。

### AC-A11：反馈 primary owner

- 初始状态：存在成功、失败、阻断、审计、恢复或跨页面任务消息。
- 事件序列：执行操作、产生错误、任务完成或切换页面。
- 预期状态：每条完整消息仅有一个 primary owner；Toast 不是唯一错误、成功回执、审计凭证或恢复入口；Tooltip/Popover 不承载唯一必读内容。
- DOM/ARIA：Alert、Notification 和页面内回执各自按语义暴露且不重复播报；运行时未验证则标注未验证。
- 事件日志：记录 primary owner、消息生命周期和恢复入口。

### AC-A12：响应式与报告零值

- 初始状态：已声明页面能力及不适用能力。
- 事件序列：在窄屏、触摸或键盘路径使用页面并产出应用报告。
- 预期状态：仅折叠低频内容，核心任务、权限、恢复、审计回执和危险确认持续可达；报告声明所有 owner、能力与未验证边界；不适用能力提供 DOM、state、handler/event、request 四类零值证据。
- DOM/ARIA：折叠后核心内容仍存在可访问路径；浏览器、屏幕阅读器、触摸设备和真实组件运行时未执行时均明确标为未验证。
- 事件日志：记录断点/设备验证范围；未验证项不生成通过结论。
