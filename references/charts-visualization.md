# 图表与可视化交互规范

本文件是图表、可视化、报表图形、仪表盘图表、趋势图、折线图、柱状图、条形图、面积图、饼图、环图、散点图、气泡图、漏斗图、排行图、热力图、组合图、迷你趋势图、图例、坐标轴、数据标签、参考线、阈值线、图表 tooltip、图表钻取、图表联动、图表导出和查看明细的唯一 owner。

图表不是装饰，也不是图表库默认配置的直接输出。图表必须让用户理解数据来自哪里、代表什么口径、使用什么单位、当前是否完整、是否受权限过滤、如何交互、如何恢复，以及在移动端和辅助技术中如何获得等价信息。

图表创建、编辑、配置、指标/维度/聚合配置、图形类型切换、图表预览、保存图表、发布图表、加入仪表盘和图表构建器场景还必须执行 `references/chart-visualization-builders.md`；本文件继续负责预览图表和已发布图表的展示语义。

概览页、仪表盘首页、管理台首页、运营看板、业务看板、指标总览、报表总览和 dashboard landing 中的图表必须同时执行 `references/overview-dashboard-pages.md`；本文件负责单个图表的图形语义，`overview-dashboard-pages.md` 负责图表与 KPI、明细、导出、筛选、时间范围和刷新状态共享页面级快照。

## 状态模型

每个图表必须声明 `chartState`，至少包含：

| 字段 | 要求 |
| --- | --- |
| `chartOwnerId` | 图表 owner；同一报表多个图表不得共用隐式全局状态。 |
| `chartKind` | `line`、`bar`、`stackedBar`、`area`、`pie`、`donut`、`scatter`、`bubble`、`funnel`、`ranking`、`heatmap`、`sparkline`、`combo` 等。 |
| `dataSnapshot` | 数据版本、筛选快照、时间范围、时区、权限范围、刷新时间、数据延迟和行数/点数。 |
| `metricBinding` | 指标名、口径、单位、聚合方式、分母、排除项、比较基准和权限范围。 |
| `dimensionBinding` | x/y/color/size/facet 等维度字段、分组语义、排序、缺失值策略和 series 身份。 |
| `encodingPolicy` | 颜色、形状、线型、堆叠、面积、大小、透明度、标签和选中编码。 |
| `axisPolicy` | 轴标题、字段、刻度、单位、零基线、截断、对数轴、双轴、百分比堆叠和格式化规则。 |
| `legendPolicy` | 图例项、顺序、颜色/线型映射、可见性、toggle 行为、键盘可达性和隐藏项说明。 |
| `tooltipPolicy` | tooltip 内容、数据点绑定、快照绑定、键盘/触摸等价路径和非唯一信息边界。 |
| `interactionPolicy` | hover、highlight、selection、legend toggle、drilldown、brush、zoom、联动筛选、导出和查看明细能力。 |
| `feedbackState` | `loading`、`empty`、`zero-results`、`partial`、`stale`、`refresh-error`、`permission-denied` 或 `metric-unavailable`。 |
| `responsivePolicy` | 移动端替代表达、最小可读尺寸、横向滚动、摘要、完整图入口和明细入口。 |
| `a11yPolicy` | 可访问名称、文本摘要、数据表替代、图例/数据点键盘路径和公告策略。 |

## 原子规则

| ID | 规则 |
| --- | --- |
| CHV-SCOPE-01 | 图表、可视化、报表图形、趋势图、折线图、柱状图、面积图、饼图、散点图、漏斗图、排行图、热力图、组合图和迷你趋势图必须归属 `chartState`。 |
| CHV-SCOPE-02 | 图表 owner 负责图表如何表达数据、状态和交互；业务指标定义、筛选草稿、明细表、危险导出和页面导航仍归对应 owner。 |
| CHV-SCOPE-03 | 图表不能从存在数据表或接口数据自动推导选择、钻取、导出、订阅或联动能力；能力必须显式声明。 |
| CHV-SCOPE-04 | 报表页中图表、指标卡、明细表和导出任务共享同一筛选/权限/时间快照时，必须引用同一快照。 |
| CHV-SCOPE-05 | 小趋势图和 sparkline 也必须有可达口径、单位、范围和状态说明，不得只作为无语义装饰。 |
| CHV-DATA-01 | 每个图表必须声明 `chartState.dataSnapshot` 与 `metricBinding`。 |
| CHV-DATA-02 | 图表必须展示或可达地说明指标名、口径、单位、时间范围、时区、数据延迟、刷新时间和权限范围。 |
| CHV-DATA-03 | 计算失败、数据延迟、部分数据、采样、截断、权限过滤和口径不可用必须可见，不得伪装成完整数据。 |
| CHV-DATA-04 | 图表标题、副标题和说明必须反映当前已应用筛选和数据快照；不得读取正在编辑的筛选草稿。 |
| CHV-DATA-05 | 数据点缺失、0、null、无权限、尚未产生和被过滤必须有不同语义，不得画成同一种空白。 |
| CHV-ENC-01 | 颜色、面积、大小、线型、堆叠、排序和透明度必须有稳定语义，不得仅为“看起来好看”改变含义。 |
| CHV-ENC-02 | 颜色不得作为唯一语义来源；状态、series、正负、风险、选中和禁用必须有文本、图例、形状、线型或标签等冗余表达。 |
| CHV-ENC-03 | 多 series 图表必须有可理解图例；图例项顺序、颜色、线型和图中编码必须一致。 |
| CHV-ENC-04 | 堆叠、百分比堆叠、归一化、排序和分组必须说明业务含义；不得让用户误以为是原始绝对值。 |
| CHV-ENC-05 | 颜色语义不得跨同一页面相互冲突；同一状态或 series 在同一上下文中使用稳定映射。 |
| CHV-AXIS-01 | 坐标轴必须声明字段、单位、刻度格式和排序规则。 |
| CHV-AXIS-02 | 非零基线、截断轴、对数轴、双轴、百分比堆叠和归一化必须显式标注。 |
| CHV-AXIS-03 | 双轴图必须说明左右轴分别代表什么，并避免让不同单位的线条看似同一尺度。 |
| CHV-AXIS-04 | 时间轴必须声明时区、粒度、缺失点策略和是否连续；离散类目不得伪装成连续时间趋势。 |
| CHV-AXIS-05 | 轴标签过密、过长或移动端空间不足时，必须提供可读替代，不得裁掉关键单位或类目。 |
| CHV-TIP-01 | 图表 tooltip 不能承载唯一必读信息；键盘和触摸用户必须有等价路径。 |
| CHV-TIP-02 | tooltip 内容必须绑定当前数据点、series、指标口径和 `dataSnapshot`。 |
| CHV-TIP-03 | hover 离开、刷新、权限变化、断点转换、route/unmount 或 trigger 消失后，tooltip 不得悬空。 |
| CHV-TIP-04 | 参考线、阈值线、异常标记和 annotation 必须说明来源、含义、适用时间和权限边界。 |
| CHV-TIP-05 | tooltip、annotation 和数据标签不得泄露无权限对象、series、内部 ID 或旧缓存。 |
| CHV-INTERACT-01 | Hover/highlight、legend toggle、drilldown、brush、zoom、联动筛选、导出和查看明细必须在 `interactionPolicy` 中声明。 |
| CHV-INTERACT-02 | 图表选择、legend toggle、brush 或 zoom 不得静默改变页面筛选；只有明确应用后才能影响 `appliedFilters` 或请求。 |
| CHV-INTERACT-03 | Drilldown 必须声明目标、来源快照、权限复核、返回路径和失效恢复。 |
| CHV-INTERACT-04 | 重置缩放、清除选择、恢复全部 series 和返回总览必须可见、可访问，且不依赖 hover。 |
| CHV-INTERACT-05 | 图表交互不能破坏明细表、指标卡或导出任务的快照一致性。 |
| CHV-STATE-01 | 图表必须区分 loading、empty、zero-results、partial、stale、refresh-error、permission-denied 和 metric-unavailable。 |
| CHV-STATE-02 | 刷新失败应保留旧图并标记 stale 或 refresh-error，不得直接清空造成“没有数据”的误解。 |
| CHV-STATE-03 | 无权限状态不得泄露 series 名称、数量、对象名、筛选值、内部 ID 或旧缓存。 |
| CHV-STATE-04 | 空态必须说明是当前权限无数据、筛选无结果、指标尚未产生、计算失败、口径不可用还是数据延迟。 |
| CHV-STATE-05 | 部分数据、采样、截断和 Top N 必须标注范围和遗漏含义。 |
| CHV-EXPORT-01 | 图表导出必须说明导出的是当前可见数据、当前筛选全量数据、聚合后数据、原始明细还是图片。 |
| CHV-EXPORT-02 | 导出、复制图片、复制数据和查看明细必须绑定当前 `dataSnapshot`、权限版本和请求身份。 |
| CHV-EXPORT-03 | 敏感导出读取 `risk-actions.md`，明细表读取 `data-tables.md`，异步任务读取 `admin-console.md`。 |
| CHV-EXPORT-04 | 导出入口不可用时必须说明原因；原因不能只放在 hover tooltip。 |
| CHV-EXPORT-05 | 导出的图表或数据必须携带口径、时间范围、时区、筛选快照、权限范围、刷新时间和数据延迟。 |
| CHV-RSP-01 | 移动端可以把复杂图表转换为摘要卡、分段图、可横向滚动图、明细表或“查看完整图表”独立页。 |
| CHV-RSP-02 | 移动端不得删除图表标题、口径、单位、图例/series 含义、状态说明、错误/权限说明、数据延迟、刷新时间、导出/明细入口和恢复路径。 |
| CHV-RSP-03 | 小屏下 tooltip 必须有触摸和键盘等价路径；不能只依赖 hover。 |
| CHV-RSP-04 | 横向滚动图必须保留轴、图例、当前范围和滚动位置反馈；不得让用户失去当前位置。 |
| CHV-RSP-05 | 图表在 200% 缩放、系统字体放大、低高度和安全区域下仍必须可读或提供等价摘要/明细。 |
| CHV-A11Y-01 | 每个图表必须有可访问名称和文本摘要，说明图表展示什么、范围是什么、主要结论或当前状态是什么。 |
| CHV-A11Y-02 | 可交互图表必须支持键盘路径；图例 toggle、数据点焦点、drilldown、缩放和重置必须可达。 |
| CHV-A11Y-03 | 图表必须提供数据表替代或等价明细入口，尤其是多 series、密集点和颜色编码场景。 |
| CHV-A11Y-04 | 状态、错误、刷新失败、权限降级和筛选联动变化必须由唯一 owner 公告，避免重复播报。 |
| CHV-A11Y-05 | 动画不得成为理解变化的唯一方式，并必须遵循 reduced-motion 偏好。 |
| CHV-LIFE-01 | 图表请求、刷新、联动、tooltip、动画和导出回调必须绑定 live owner、`dataSnapshot` 和权限版本。 |
| CHV-LIFE-02 | 迟到响应不得覆盖较新的图表、筛选、权限状态或错误。 |
| CHV-LIFE-03 | route/unmount、Tabs 切换、断点转换和权限变化必须清理仅属于该图表 owner 的 tooltip、监听、动画、导出回执和请求。 |
| CHV-LIFE-04 | 图表和明细表从不同请求返回时，必须展示快照差异或等待一致快照；不得静默呈现互相矛盾的数据。 |
| CHV-LIFE-05 | 未执行真实浏览器、读屏、键盘、触摸、缩放、移动端和真实数据检查时，必须标为未验证。 |

## 场景化要求

### 报表图表

- 报表图表必须声明数据快照、指标口径、时间范围、时区、筛选、权限范围、刷新时间和数据延迟。
- 图表、指标卡和明细表共享范围时必须引用同一快照；不同范围必须可见说明。
- 未声明钻取、导出、订阅或联动时，对应入口为 0。

### 趋势图和时间序列

- 时间轴必须声明时区、粒度、缺失点、补零、采样和是否连续。
- “今天”“近 7 天”等相对时间必须读取已冻结的日期时间快照。
- 趋势线不能用断点、平滑或插值隐藏缺失数据；插值必须标注。

### 占比、排行和 Top N

- 饼图、环图、百分比堆叠和 Top N 必须说明分母、排序、是否包含“其他”和被过滤范围。
- 排行图必须说明排序字段、排序方向、并列处理和权限过滤。
- Top N 不得伪装成全量分布。

### 交互图表

- Legend toggle、brush、zoom、drilldown 和联动筛选必须可撤销或可重置。
- 图表交互影响查询条件时，必须经过 `query-filters.md` 的草稿/应用边界。
- Drilldown 后返回必须恢复来源图表、筛选、滚动、焦点和权限安全状态。

### 移动端图表

- 复杂图表可以转换为摘要卡 + 查看明细，或独立完整图表页。
- 移动端替代表达必须保留图表标题、口径、单位、图例/series 含义、状态说明、错误/权限说明、数据延迟、刷新时间、导出/明细入口和恢复路径。
- hover tooltip 信息必须有触摸、键盘或明细等价路径。

## 完成前检查

1. 是否声明 `chartState` 及全部必要字段。
2. 是否展示或可达地说明指标名、口径、单位、时间范围、时区、数据延迟、刷新时间和权限范围。
3. 颜色、tooltip、动画、图标、大小或形状是否不是唯一语义来源。
4. 坐标轴是否声明字段、单位、刻度格式和排序规则。
5. 非零基线、截断轴、对数轴、双轴、百分比堆叠和归一化是否显式标注。
6. 图表交互能力是否在 `interactionPolicy` 中声明，并有重置/恢复路径。
7. loading、empty、zero-results、partial、stale、refresh-error、permission-denied 和 metric-unavailable 是否可区分。
8. 无权限状态、tooltip、annotation、导出和明细是否不会泄露敏感信息或旧缓存。
9. 移动端是否保留标题、口径、单位、图例/series、状态、错误/权限、数据延迟、刷新时间、导出/明细和恢复路径。
10. 未实际执行运行时检查时，是否明确标为未验证。
