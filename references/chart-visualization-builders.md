# 图表与可视化创作配置交互规范

适用于图表创建、创建图表、新建图表、编辑图表、图表配置、可视化配置、图表构建器、可视化构建器、报表图表配置、仪表盘图表配置、图表配置向导、指标配置、维度配置、聚合配置、图形类型切换、图表预览、保存图表、发布图表、加入仪表盘、复制图表配置、导出图表配置、图表字段映射、图表钻取配置和图表联动配置。

本文件是图表配置器草稿、预览、校验、保存、发布、权限和响应式承载的唯一 owner。图表预览和已发布图表的展示语义继续执行 [图表与可视化交互规范](charts-visualization.md)；通用复杂编辑器生命周期继续执行 [复杂编辑器和构建器交互规范](complex-editors-builders.md)。兼容规则全部执行。

## 范围与非目标

- 范围：数据源选择、字段选择、指标配置、维度配置、聚合配置、图形类型切换、编码配置、轴/图例/tooltip 配置、筛选绑定、钻取、联动、导出、查看明细、预览、保存、发布、加入仪表盘和复制配置。
- 范围：图表配置器从已保存或已发布配置进入编辑、从草稿生成预览、保存草稿、覆盖配置、发布到仪表盘或外部嵌入、撤销发布、版本冲突和权限变化。
- 图表构建器中的 Top N、阈值、轴范围、百分比、权重、排序序号、小数位、单位倍率、采样数量和数值筛选必须同时执行 `references/numeric-amount-inputs.md`；图表构建器 owner 负责配置草稿、预览和发布边界，数字 owner 负责 `numericInputState`、单位/精度/边界、草稿解析、格式化、粘贴、IME 和提交快照。
- 非目标：具体图表库、BI 引擎、SQL 编辑器、指标平台、数据建模方案和业务口径来源。本规范只要求前端交互明确读取、展示和保护这些边界。

## `chartBuilderState`

每个图表配置器必须声明 `chartBuilderState`，并包含 `chartBuilderOwnerId`、`sourceConfigSnapshot`、`dataSourceBinding`、`metricDraft`、`dimensionDraft`、`encodingDraft`、`interactionDraft`、`filterBindingDraft`、`previewState`、`validationState`、`savePolicy`、`publishPolicy`、`permissionBoundary` 和 `responsivePolicy`。

- `chartBuilderOwnerId`：当前图表配置器实例身份，绑定对象、租户/工作区、权限版本、来源配置版本和承载面。
- `sourceConfigSnapshot`：进入编辑时读取的已保存或已发布配置快照，包括版本、作者、更新时间、发布状态和只读状态。
- `dataSourceBinding`：数据源、数据集版本、可用字段、字段类型、权限范围、刷新时间、数据延迟和不可用原因。
- `metricDraft`：指标选择、聚合方式、单位、分母、过滤条件、比较基准、计算状态和口径说明草稿。
- `dimensionDraft`：x/y/color/size/facet/group 等维度草稿、排序、缺失值策略、Top N、其他项和权限过滤。
- `encodingDraft`：图形类型、颜色、线型、堆叠、面积、轴、图例、tooltip、数据标签、参考线和阈值线草稿。
- `interactionDraft`：drilldown、legend toggle、brush、zoom、联动筛选、导出、查看明细和加入仪表盘能力草稿。
- `filterBindingDraft`：图表内筛选、页面筛选绑定、时间范围绑定、URL 安全、默认值和应用边界。
- `previewState`：预览请求身份、预览数据快照、样本/全量边界、权限过滤、错误、过期和与保存配置的一致性。
- `validationState`：图形类型兼容、字段类型兼容、指标/维度数量、聚合合法性、口径缺失、权限缺失、钻取目标、导出范围和隐藏面板错误。
- `savePolicy`：保存草稿、保存副本、覆盖配置、幂等键、防重复、保存结果回执和未知结果恢复。
- `publishPolicy`：发布、加入仪表盘、替换已发布图表、撤销发布、发布结果未知、旧图表配置失效和审计入口。
- `permissionBoundary`：数据源、字段、指标、预览、保存、发布、复制、导出、钻取和明细权限收敛。
- `responsivePolicy`：移动端、虚拟键盘、字段面板、预览面板、拖拽配置、错误定位、底部操作和安全区域策略。

## 草稿、预览、保存和发布分层

指标选择、维度选择、聚合方式、图形类型、编码、筛选绑定、钻取、导出和明细能力的编辑只能写入对应草稿字段。

预览成功不等于保存成功；保存成功不等于发布成功；发布请求发送不等于仪表盘或外部嵌入已生效；加入仪表盘请求发送不等于仪表盘已更新。

保存和发布必须读取当前 `chartBuilderState` 的完整草稿、校验状态、权限版本、数据源版本、来源配置版本和幂等键。校验未完成、预览过期、权限不可证明、来源版本冲突或图形类型不兼容时，请求数为 0。保存、覆盖、发布、加入仪表盘、撤销发布、删除图表和敏感导出能力必须分别表达意图；高风险动作执行 [危险操作与恢复交互规范](risk-actions.md)。

## 图形类型与字段兼容性

每种图形类型必须声明可接受的指标数量、维度数量、字段类型、时间轴要求、是否允许多 series、是否允许堆叠、是否允许百分比、是否允许双轴和是否需要分母。

切换图形类型时，不能静默删除不兼容配置；必须展示迁移摘要、待修复项、保留项、丢弃项和撤销/取消路径。

不能让“预览能画出来”替代配置合法性。折线图、柱状图、饼图、散点图、热力图、漏斗图、排行图、组合图和迷你趋势图都必须由明确兼容规则决定是否可保存。组件库能渲染出某种图形，只能说明渲染层有输出，不能证明业务配置、口径、权限、导出或钻取合法。

## 数据源、指标和维度边界

数据源字段列表必须绑定数据集版本、权限范围、字段类型和刷新时间。

无权限字段、不可用字段、已删除字段、类型变化字段和旧缓存字段不得进入可选列表、预览、保存配置、导出配置或错误详情。指标草稿必须声明口径、单位、聚合、分母、排除项和比较基准。维度草稿必须声明分组语义、排序、缺失值策略、Top N 和“其他”项。

保存时不得读取 Select query、active option、筛选草稿、hover 字段、预览高亮、当前可见结果或旧缓存。图表内筛选、页面筛选绑定和时间范围绑定必须说明读取已提交值、继承页面范围还是另有独立快照；未提交草稿不能进入预览、保存、发布、URL 或导出配置。

## 预览可信边界

预览必须声明读取的是当前草稿、已保存配置还是已发布配置，并说明预览数据是样本、当前筛选全量、聚合后结果还是权限过滤后的结果。

预览失败、预览超时、预览权限不足、预览过期或预览与保存配置不一致时，不能清空草稿，也不能允许发布绕过校验。预览结果未知不能伪装成成功或失败，必须提供重试预览、查看错误、保存草稿或退出恢复路径。

预览图表本身必须执行 `charts-visualization.md` 的展示规则：口径、单位、时间范围、图例、tooltip、空态、权限和移动端替代表达不能因为“只是预览”而省略。

## 完整校验和错误定位

配置器必须校验完整配置，而不是只校验当前可见面板。

折叠面板、隐藏字段、高级配置、钻取目标、导出范围、tooltip 字段、颜色映射、双轴、Top N、权限不可见字段、旧数据源字段和旧图表类型残留都必须进入 `validationState`。

错误必须定位到字段、指标、维度、编码、轴、图例、tooltip、钻取、导出、筛选绑定、预览或发布设置。无法定位到具体控件时，错误摘要必须说明影响范围和下一步，不能只 Toast。错误定位必须能打开折叠面板、切换到隐藏配置区或进入等价移动端步骤。

## 权限、版本和旧配置清理

权限、租户/工作区、数据源版本、字段版本、指标口径、来源配置版本、发布版本、仪表盘版本或会话状态变化后，旧字段列表、旧预览、旧保存按钮、旧发布按钮、旧导出配置、旧钻取目标、旧颜色映射、旧复制内容、旧焦点目标和旧 ARIA 引用必须失效或重新证明安全。

无权或未启用时，数据源选择、字段选择、指标选择、预览、保存、发布、复制、导出、钻取配置、加入仪表盘和查看明细配置的 DOM、state、handler、request 和快捷键入口为 0。

无权限状态不得泄露数据源名称、字段名、指标名、维度名、图表名称、仪表盘名称、钻取目标、导出范围、错误明细、内部 ID、旧预览、旧配置片段、旧颜色映射或旧缓存。只读、禁用、隐藏、无权限和未启用必须分开表达。

## 移动端和响应式承载

移动端不得删除数据源说明、指标配置、维度配置、图形类型、预览、完整校验、错误定位、保存草稿、发布/加入仪表盘、权限原因、版本冲突、恢复路径和离开保护。

复杂配置可以在移动端转为分步配置、全屏 Drawer、独立页或“配置 + 预览”切换视图，但必须保留同一个 `chartBuilderState`、同一个草稿、同一个校验状态、同一个预览身份和同一个保存/发布门禁。

虚拟键盘、低高度、横竖屏、系统字体放大、拖拽排序、字段面板和底部操作出现后，关键配置、预览状态、错误摘要、保存、取消和发布仍必须可见或可滚动到达。拖拽配置、字段排序、图形类型选择和面板切换必须提供点击、键盘或列表式等价路径。

## 与其他 owner 的关系

- [图表与可视化交互规范](charts-visualization.md)：负责图表展示。配置器的预览图表和已发布图表都必须执行展示 owner。
- [复杂编辑器和构建器交互规范](complex-editors-builders.md)：负责通用复杂编辑器生命周期。本 owner 是图表配置器专属细化，不能降低通用草稿、校验、预览、保存、发布和移动端规则。
- [表单状态、校验与错误交互规范](forms.md)：负责字段级 dirty/touched、错误和提交边界。本 owner 负责跨字段图表配置合法性。
- [查询条件与筛选交互规范](query-filters.md)：负责筛选草稿与已应用条件。图表配置保存不得读取未提交筛选草稿。
- [日期时间与时区交互规范](date-time-ranges.md)：负责时间范围、时区和相对时间。图表配置预览、保存和发布必须绑定明确时间快照或声明继承策略。
- [数据表格交互规范](data-tables.md)：负责明细表和查看明细入口。
- [危险操作与恢复交互规范](risk-actions.md)：负责覆盖发布图表、替换仪表盘图表、删除图表、撤销发布、敏感导出能力等高风险动作。
- [权限、租户与可见性交互规范](permissions-tenancy-visibility.md)：负责无权限、只读、隐藏、禁用、未启用和旧缓存无泄露。
- [导出、下载与结果产物交付交互规范](exports-downloads-artifacts.md)：负责导出图表配置、导出预览数据、导出明细和下载结果产物。
- [响应式与自适应交互规范](responsive-adaptive.md)：负责移动端、虚拟键盘、触摸、缩放和安全区域。

## 完成前检查

- 检查每个图表配置器都有 `chartBuilderState`，且十四个字段可定位到配置身份、来源快照、数据源、指标、维度、编码、交互、筛选绑定、预览、校验、保存、发布、权限和响应式策略。
- 验证指标、维度、聚合、图形类型、编码、筛选绑定、钻取、导出和明细能力只写入草稿，不直接写入已保存配置或已发布图表。
- 验证预览成功、保存成功、发布请求发送、发布生效、加入仪表盘请求发送和仪表盘更新是不同状态。
- 验证图形类型兼容规则覆盖指标数量、维度数量、字段类型、时间轴、多 series、堆叠、百分比、双轴和分母；切换图形类型不会静默丢配置。
- 验证保存不会读取 Select query、active option、筛选草稿、hover 字段、预览高亮、当前可见结果或旧缓存。
- 验证预览声明读取来源、样本/全量/聚合/权限过滤边界，并且预览图表执行 `charts-visualization.md`。
- 验证完整校验覆盖折叠面板、隐藏字段、高级配置、钻取目标、导出范围、tooltip 字段、颜色映射、双轴、Top N、权限不可见字段、旧数据源字段和旧图表类型残留。
- 验证权限、租户/工作区、数据源版本、字段版本、指标口径、来源配置版本、发布版本、仪表盘版本或会话状态变化后，旧字段列表、旧预览、旧保存按钮、旧发布按钮、旧导出配置、旧钻取目标、旧颜色映射、旧复制内容、旧焦点目标和旧 ARIA 引用失效或重新证明安全。
- 验证无权或未启用时，相关 DOM、state、handler、request 和快捷键入口为 0。
- 在移动端、虚拟键盘、低高度、横竖屏、系统字体放大、拖拽排序、字段面板和底部操作下，确认数据源说明、指标配置、维度配置、图形类型、预览、完整校验、错误定位、保存草稿、发布/加入仪表盘、权限原因、版本冲突、恢复路径和离开保护可到达。
- 真实浏览器、真实图表库、真实数据源、真实预览、真实权限切换、键盘、触摸、读屏和移动端视口未执行时，必须标为“未验证”。
