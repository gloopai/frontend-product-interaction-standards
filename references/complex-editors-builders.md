# 复杂编辑器和构建器交互规范

本文件是复杂编辑器、构建器、编辑器、富文本编辑器、Markdown 编辑器、代码编辑器、JSON 编辑器、YAML 编辑器、模板编辑器、规则构建器、条件构建器、流程编排器、工作流编排、节点编辑、画布编辑、拖拽构建、字段映射、表达式编辑、公式编辑、可视化配置、报表构建器、自动化规则和 AI 生成配置的唯一 owner。

## 范围与非目标

本规范覆盖用户编辑一个可保存、可发布、可预览、可复用或可执行产物的完整工作台：文本内容、结构化配置、规则树、条件组、节点图、画布、字段映射、模板片段、表达式、公式、测试运行、预览、保存草稿、发布、回滚、导入片段、导出配置、复制片段、AI 生成和协作状态。

本规范不替代 [表单状态、校验与错误交互规范](forms.md) 的字段级 dirty、touched 和提交快照；不替代 [页面级表单操作栏与保存区交互规范](page-form-action-bars.md) 的页面保存栏；不替代 [危险操作与恢复交互规范](risk-actions.md) 的危险确认；不替代 [上传与导入交互规范](uploads-imports.md) 的文件上传和导入任务；不替代 [图表与可视化交互规范](charts-visualization.md) 的图表呈现。图表配置器、可视化构建器、报表图表配置和仪表盘图表配置还必须执行 `references/chart-visualization-builders.md`；本文件继续提供通用复杂编辑器生命周期，不能降低图表配置器 owner 的专属规则。

## `editorBuilderState`

每个复杂编辑器或构建器必须声明 `editorBuilderState`：

| 字段 | 含义 |
| --- | --- |
| `editorOwnerId` | 编辑器实例身份，绑定页面、对象、租户/工作区、权限版本、来源版本和当前承载面。 |
| `sourceSnapshot` | 进入编辑器时读取的服务端或可信来源快照，包括版本、更新时间、作者、权限、发布状态和只读状态。 |
| `draftModel` | 当前编辑草稿，包括文本、结构、节点、边、字段映射、条件组、变量引用、附件引用、画布坐标和本地未保存变化。 |
| `validationState` | 同步校验、异步校验、结构校验、权限校验、引用校验、循环依赖、未完成校验、错误定位和阻断级别。 |
| `previewState` | 预览输入、预览数据来源、脱敏策略、权限过滤、运行状态、错误、过期状态和与生产一致性的说明。 |
| `versionPolicy` | 来源版本、草稿版本、保存版本、发布版本、回滚目标、冲突处理、版本对比和旧版本只读策略。 |
| `savePolicy` | 保存草稿、保存副本、自动保存、手动保存、幂等键、防重复提交和保存结果回执。 |
| `publishPolicy` | 发布、应用、启用、提交审核、上线、下线、回滚、审批和发布结果未知的恢复策略。 |
| `importExportPolicy` | 导入片段、粘贴配置、导出配置、复制片段、模板下载、错误报告和脱敏边界。 |
| `permissionBoundary` | 编辑、预览、保存、发布、导入、导出、复制、回滚、查看差异和测试运行的权限收敛。 |
| `collaborationPolicy` | 多人编辑、锁定、只读接管、远端更新、冲突、游标/选区显示和迟到事件归属。 |
| `responsivePolicy` | 移动端、窄屏、低高度视口、虚拟键盘、触摸拖拽、画布缩放、横竖屏和全屏承载策略。 |

`editorBuilderState` 只负责复杂编辑器整体生命周期。字段控件仍归 Forms owner；页面保存栏仍归 Page Form Action Bar owner；按钮语义仍归 Buttons owner；离开保护仍归 Navigation owner；发布、回滚、覆盖、丢弃、删除、下线和导入覆盖等高风险动作仍进入 Risk Actions owner。

## 草稿、保存、发布和意图分层

草稿、预览、保存、发布、应用、启用、提交审核、回滚、导入、导出和复制必须是不同意图。

输入、拖拽、节点连接、格式化、粘贴、AI 生成、导入片段和自动修复只能写入 `draftModel`，不能静默写入已保存版本、已发布版本、生产配置或外部系统。任何自动行为若会改变可执行结果，都必须先表现为草稿差异，再经过相同校验、差异说明、权限复核和保存/发布门禁。

保存草稿成功不等于发布成功。预览成功不等于保存成功。发布请求发送不等于发布已生效。发布结果未知不得伪装成成功或失败，必须提供刷新版本、查看发布状态、查看审计、重试或回滚路径。

保存、发布、应用、启用和提交审核必须读取当前适用的 `draftModel`、`validationState`、权限版本、租户/工作区、来源版本和幂等键；校验未完成、结构错误、权限不可证明、版本冲突或发布前置条件未满足时，请求数为 0。

## 结构完整性与错误定位

复杂编辑器必须校验完整结构，而不是只校验当前可见区域。

折叠节点、隐藏面板、未展开分支、不可见字段、禁用节点、孤立节点、断开的边、循环依赖、缺失变量、重复 key、非法表达式、未映射字段、权限不可见引用、旧版本引用和外部资源失效都必须进入 `validationState`。

错误必须能定位到具体文本范围、字段、节点、边、条件组、模板片段、变量引用或画布区域。无法定位到具体位置时，必须在错误摘要中说明影响范围和下一步，不能只 Toast。

错误摘要必须能导航到可修复位置或等价承载面。折叠分组、隐藏面板、画布缩放、节点搜索、只读引用和移动端分步承载不得让错误成为“知道有错但找不到”的状态。

## 预览可信边界

预览必须声明它读取的是 `draftModel`、已保存版本还是已发布版本。预览数据必须声明来源、时间、权限过滤、脱敏策略、样本限制和是否代表生产结果。

预览失败、预览超时、预览权限不足、预览数据过期、预览与生产不一致或预览结果未知时，不得清空草稿，不得阻断用户复制错误信息、查看错误定位、保存草稿或退出恢复。

测试运行、模拟执行、示例数据预览和生产预览必须分开表达。示例预览不能暗示生产可用；生产预览不能绕过权限、脱敏、审计和风险边界。

## 版本、冲突、协作和回滚

编辑器必须区分来源版本、草稿版本、保存版本、发布版本和回滚目标版本。

来源版本变化、权限版本变化、租户/工作区变化、远端发布变化、协作锁变化或对象状态变化后，旧草稿、旧预览、旧校验结果、旧保存按钮、旧发布按钮、旧快捷键、旧复制片段、旧导出链接和旧焦点目标必须失效或重新证明安全。

多人编辑、锁定、只读接管、远端更新、迟到协作事件、游标/选区和自动保存结果必须绑定 `editorOwnerId`、来源版本、权限版本、租户/工作区和草稿版本。不匹配时只能进入冲突说明、只读状态、重新加载、比较差异或安全丢弃，不得直接覆盖当前 `draftModel`。

回滚、覆盖发布版本、丢弃草稿、删除节点、批量替换、导入覆盖、发布到生产、下线生产配置和撤销发布必须进入 [危险操作与恢复交互规范](risk-actions.md)。确认完成前请求数为 0。

## 权限、敏感信息与旧入口清理

无权或未启用时，编辑、预览、保存、发布、导入、导出、复制、回滚、查看差异和测试运行的 DOM、state、handler、request 和快捷键入口为 0。

无权限状态不得泄露配置名称、节点名称、变量名、字段名、表达式、模板内容、密钥片段、内部 ID、依赖关系、错误明细、预览数据、版本差异、协作者身份或旧缓存。只读、禁用、隐藏、无权限和未启用必须分开表达，不能用一个灰色按钮代替。

复制、导出、模板下载、查看真实值、AI 生成上下文和错误报告必须复核权限、租户/工作区、来源版本、脱敏策略和请求身份。权限、租户/工作区、对象状态、来源版本或会话状态变化后，旧复制片段、旧导出文件、旧预览结果、旧错误报告和旧 AI 上下文必须失效或重新证明安全。

## 自动保存、AI 生成和外部输入

自动保存必须声明触发条件、节流策略、冲突策略、失败回执和离线恢复。自动保存失败不得让用户误以为草稿已保存；自动保存成功也不得伪装成已发布或已应用。

AI 生成、自动补全、批量格式化、导入片段、粘贴 JSON/YAML、模板套用和示例填充都只是草稿来源，必须经过相同校验、差异说明、权限复核和保存/发布门禁。

外部输入不得绕过危险操作确认、敏感字段脱敏、权限过滤、结构完整性检查、版本冲突检查或审计绑定。来自剪贴板、上传文件、模板库、AI、浏览器历史、外部系统回放或 URL 参数的内容都必须标记来源，并只在当前 live editor owner 中生效。

## 移动端、虚拟键盘和触摸承载

移动端不得删除编辑、预览、校验、保存草稿、发布/提交、错误摘要、错误定位、版本/冲突说明、权限原因、恢复路径和离开保护。

复杂画布、多面板规则构建器或代码/预览并排编辑器在移动端可以升级为全屏 Drawer、全屏编辑页或分步编辑模式，但必须保留同一个 `editorBuilderState`、同一个草稿版本、同一个校验结果、同一个保存/发布门禁和同一个恢复路径。

虚拟键盘、触摸拖拽、缩放、横竖屏切换和低高度视口变化后，当前编辑位置、错误定位、预览入口、保存入口、发布入口、撤销/恢复入口和离开保护仍必须可见或可滚动到达。

拖拽、长按、双指缩放、画布框选、节点连接和精确指针操作必须提供键盘、点击或列表式等价路径；复杂手势不得成为保存、发布、错误修复、恢复或权限说明的唯一入口。

## 与其他 owner 的关系

- [表单状态、校验与错误交互规范](forms.md)：字段值、dirty/touched、校验消息和错误摘要继续执行 Forms 规则；本 owner 负责跨字段、跨节点、跨版本和结构完整性。
- [页面级表单操作栏与保存区交互规范](page-form-action-bars.md)：页面保存栏、取消、返回、放弃、底部避让和结果回执继续执行保存区规则；本 owner 提供草稿、校验、预览、保存和发布状态。
- [按钮交互规范](buttons.md)：按钮语义、loading、禁用原因、主次关系和危险视觉继续执行 Button 规则。
- [导航与路由交互规范](navigation-routing.md)：未保存离开、返回、面包屑、浏览器 Back、Tabs 和外链离开保护继续执行 Navigation 规则。
- [危险操作与恢复交互规范](risk-actions.md)：发布、回滚、覆盖、删除、丢弃、下线、导入覆盖和批量替换继续执行 Risk Actions。
- [权限、租户与可见性交互规范](permissions-tenancy-visibility.md)：权限、租户/工作区、只读、禁用、隐藏和无泄露继续执行 Permissions 规则。
- [上传与导入交互规范](uploads-imports.md)：文件上传和导入任务继续执行 Uploads 规则；本 owner 只约束编辑器内导入入口和编辑结果归属。
- [导出、下载与结果产物交付交互规范](exports-downloads-artifacts.md)：导出配置、下载模板、导出预览结果和领取文件继续执行 Exports 规则。
- [复制与剪贴板操作交互规范](copy-clipboard.md)：复制片段、复制配置、复制错误和复制脱敏值继续执行 Clipboard 规则。
- [全局反馈与通知交互规范](global-feedback.md) 与 [反馈状态与状态承载规范](feedback-states.md)：Toast、Banner、状态区、空态、错误和恢复入口继续执行反馈 owner；复杂编辑器不能只 Toast。
- [响应式与自适应交互规范](responsive-adaptive.md)：移动端、触控、虚拟键盘、缩放和安全区域继续执行响应式规则。

## 完成前检查

- 验证每个复杂编辑器或构建器声明 `editorBuilderState`、`editorOwnerId`、`sourceSnapshot`、`draftModel`、`validationState`、`previewState`、`versionPolicy`、`savePolicy`、`publishPolicy`、`importExportPolicy`、`permissionBoundary`、`collaborationPolicy` 和 `responsivePolicy`。
- 验证草稿、预览、保存、发布、应用、启用、提交审核、回滚、导入、导出和复制为不同意图。
- 验证输入、拖拽、节点连接、格式化、粘贴、AI 生成、导入片段和自动修复只写入 `draftModel`，不会静默写入已保存版本、已发布版本、生产配置或外部系统。
- 验证保存草稿成功、预览成功、发布请求发送、发布已生效和发布结果未知都有不同回执和恢复路径。
- 验证完整结构校验覆盖折叠节点、隐藏面板、未展开分支、不可见字段、禁用节点、孤立节点、断开的边、循环依赖、缺失变量、重复 key、非法表达式、未映射字段、权限不可见引用、旧版本引用和外部资源失效。
- 验证错误能定位到具体文本范围、字段、节点、边、条件组、模板片段、变量引用或画布区域；无法定位时错误摘要说明影响范围和下一步，不能只 Toast。
- 验证预览声明读取版本、数据来源、时间、权限过滤、脱敏策略、样本限制和生产一致性。
- 验证来源版本、权限版本、租户/工作区、远端发布、协作锁或对象状态变化后，旧草稿、旧预览、旧校验结果、旧保存按钮、旧发布按钮、旧快捷键、旧复制片段、旧导出链接和旧焦点目标失效或重新证明安全。
- 验证无权或未启用时编辑、预览、保存、发布、导入、导出、复制、回滚、查看差异和测试运行的 DOM、state、handler、request 和快捷键入口为 0。
- 验证 AI 生成、自动补全、批量格式化、导入片段、粘贴 JSON/YAML、模板套用和示例填充经过相同校验、差异说明、权限复核和保存/发布门禁。
- 验证移动端保留编辑、预览、校验、保存草稿、发布/提交、错误摘要、错误定位、版本/冲突说明、权限原因、恢复路径和离开保护。
- 验证虚拟键盘、触摸拖拽、缩放、横竖屏切换和低高度视口变化后，当前编辑位置、错误定位、预览入口、保存入口、发布入口、撤销/恢复入口和离开保护仍可见或可滚动到达。
- 真实浏览器、屏幕阅读器、触控设备、真实拖拽、真实虚拟键盘、真实编辑器运行时、真实协作锁、真实保存/发布请求和真实权限切换未执行时，最终报告必须标为**未验证**，并说明所需环境。
